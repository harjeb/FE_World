# FE-Repo 交战动画（转换后）

当前全部 **77 个职业、162 个攻击武器组合**已接入动画。其中 **155 个组合**使用 FE-Repo 转换素材，共用 **57 个资源包、91 组动作图集**；飞鸵三阶的 **7 个剑／斧／魔法组合**使用[项目自绘图集](../battle-sheets/README.md)，保留鸟形坐骑。对应关系由 [全职业对照](../fe-repo-candidates/CLASS-MAP.md)（`class-map.json`）决定；`anims.json`、FE 图集、遮罩、署名和导入清单由 `gen_fe_anims.py` 从固定版本转换生成，请不要手改。

- 治疗杖不转换：回复只在地图上显示，不进交战画面。
- 所有攻击武器都有对应动画。隔一格时没有远程段的近战包仍会退回 16 帧样张或分层动作。FE 包复用来源人物形象并适配阵营色；不同武器来源的服装尚未全部统一重绘。
- 作者署名原文见 [CREDITS.md](CREDITS.md)，游戏内在「设置 · 美术鸣谢」显示。标注 IS 的原作动画版权属于 Nintendo / Intelligent Systems；本作为非商业同人项目。

## 生成

在仓库根目录运行：

```sh
python3 design/pixel-art/gen_battle_sheets.py
python3 design/pixel-art/gen_fe_anims.py
```

首次运行会把用到的脚本、帧图和预览 GIF 下载到 `~/.cache/agent-tactics/fe-repo/<版本>/`（可用 `FE_REPO_CACHE` 改位置），之后可以离线重跑。固定版本中返回 404 的帧会留下 `.missing` 标记，后续直接从缓存 GIF 补帧；网络或服务端故障不会被当作缺帧缓存。全部转换成功后才发布输出，转换失败保留之前的可用素材。输出：

- `<包>-<动作>.png`：动画图集，每行 8 格，格子大小见 `anims.json` 的 `frameSize`。几个职业共用同一包同一动作时共用一张图。
- `<包>-<动作>-mask.png`：换色遮罩，灰度 1–3 标记阵营色的三档（`a/A/l`），游戏按己方/敌方重新上色。
- `anims.json`：每个（职业, 武器）的帧序列、逐帧时长、命中帧、站位，以及各动画包的署名。
- `CREDITS.md`：各包署名原文、来源链接和用到它的职业。
- `frontend/src/battle/fe-anim-files.ts`：图集与遮罩的静态导入清单。

## 转换规则

- **读取脚本**：读取 FEBuilder 动画脚本：Mode 1 普通攻击、Mode 3 必杀、Mode 5/6 远程普通与必杀、Mode 7 闪避、Mode 9 待机。每帧时长按 1/60 秒换算。
- **近战命中**：按脚本的 `C1A`、`C08`、`C0A`、`C09`、`C0C` 命中标记取帧，没有时用 `C04`。拳击和鸟骑等包的特殊必杀标记不会提前到蓄力帧扣血。`C01`（等待扣血）之前那一帧多停 320 毫秒。
- **射击类**：弓、魔法、龙石在原作里用 `C05` 召唤箭矢、法术或龙息特效，动画包本身不画飞行物。转换后在 `C05` 帧放出画面通用的飞行物，在 `C01` 帧算命中，并在该帧多停 320 毫秒。
- **远程段**：近战包如果有 `C05` 的 Mode 5（投枪、飞斧、飞刀、魔剑），隔一格交战时播放这一段；没有远程段的近战包，隔一格时让位给原来的动作。
- **补帧**：有些包只导出了部分单帧 PNG。预览 GIF 按脚本顺序把每一步渲染一帧，所以缺的帧从 GIF 对应位置取，再按该包调色板还原成索引色。
- **朝向与裁切**：原图朝左，转换时翻成朝右，并去掉屏幕最外两圈的杂色像素。同一动作的所有帧共用一个裁切框，站立帧的脚下中点作为地面基准点。
- **站位与倍数**：`stand` 记录站立位置离屏幕中心多远。游戏里按原作间距站位，因为动画里的冲刺距离就是按这个间距画的。显示倍数为 3 倍。
- **透明背景**：优先读取调色板的透明索引，否则识别屏幕边缘的主背景色；保留原调色板索引，避免误删黑色轮廓，也不把背景染成阵营色。
- **换色**：只换阵营色，其余颜色保持原样。阵营色默认取调色板里用得最多的一组高饱和蓝、紫、绿或红；猜错的包在脚本的 `TEAM` 里按编号写死。每个阵营色换成亮度最接近的本作阵营色。
- **运行时**：等图集解码后开始计时，加载失败退回分层动画及其时间轴。图集解码按文件共用，最多缓存 8 对原图／遮罩和 32 张换色图，避免浏览多个职业后无界积累。龙人与飞行职业也以脚底基准对齐，交战画面默认 384 像素高；若图集有延伸到站立脚下的武器或特效，下沿自动加高，人物与命中点保持原位。

## 校验

```sh
python3 -m unittest discover -s design/pixel-art -p test_gen_fe_anims.py -v
npm run typecheck --prefix frontend
npm test --prefix frontend
npm run build --prefix frontend
```

转换器测试覆盖普通／多种必杀命中帧、非零背景索引、GIF 补帧、缺帧离线缓存、转换失败不覆盖旧素材、完整攻击映射及借用动作的正确署名。项目图集必须匹配职业／武器且 PNG 与遮罩均存在，转换器才接受 `P01:` 映射。前端测试按当前职业可用武器逐项要求动画存在，并检查别名、远程回退、图集导入与换色。

## 调整

- **换一包或补一个动作**：改 `fe-repo-candidates/class-map.json` 的 `weaponMap`，然后重新运行转换脚本。
- **阵营色不对**：打开该包任意一帧的调色板，把盔甲或衣服上那组颜色的编号写进 `TEAM`。
