## 输入与实测结果

| 项目 | 实际读取结果 |
| --- | --- |
| 游戏码 | `BE8J`，日版数据布局 |
| ROM 大小 | 16,777,216 字节 |
| ROM SHA-1 | `56f3d3938ec0f61d3864c95c142b03c98225fe72` |
| 内部章节 | 章节表索引9，名称 `L08`，对应显示第8章 |
| 地图 | 24×24，共576格；10种基础地形 |
| 地点事件 | 2扇门、3个宝箱、1个制压点 |
| 主要单位模板 | 出击9条、初始敌军27条、三组增援各3条，共45条 |
| 其他单位组 | 过场3条、过场3条、条件加载5条，单列在 `otherUnitGroups` |
| 地图变化 | 7组；0字保留为 `null`，表示保留原格 |
| 事件 | 从回合/交谈/地点/其他事件表和开场、结尾入口追踪，解码22段脚本、245条指令 |
| 运行时边界 | 1条 ASM 调用保留地址，未执行；未运行模拟器 |

坐标从左上角 `(0,0)` 开始，顺序为 `(x,y)`。单位同时保留入场点与 REDA 移动路径终点；特殊相对路径无法静态确认时保留 `null`，不猜测最终位置。

## ROM 与早期美版数据的差异

地图图块、576格地形、地形移动/战斗规则及7组地图变化与早期美版公开数据一致。主要单位模板有以下4处差异，新的导出保留 ROM 读数：

| 配置 | 这份 ROM | 美版公开数据 |
| --- | --- | --- |
| 第2回合 Ephraim 模板等级 | 7 | 4 |
| 第2回合 Forde 模板等级 | 9 | 6 |
| 第2回合 Kyle 模板等级 | 8 | 5 |
| 第5回合第二名骑兵的物品 | Steel Lance | Steel Lance、Javelin |

这说明跨版本参考资料不能覆盖 ROM 中实际存在的配置。`comparison.json` 只记录差异，不参与生成 ROM 的地图或单位数值。

## 已验证与剩余范围

25项 Python 检查通过，其中包含真实 ROM 的地图/事件、单位等级差异、嵌套条件加载和输入文件未修改检查。Chromium 预览交互检查通过，包括真实等级7、首领、开门、开箱、地图变化掩码、事件开关及手机宽度。重复提取的9个生成文件字节一致，输入 ROM 的 SHA-1 保持不变。

当前完成的是这份 ROM 的第8章静态提取。脚本保留了指令和直接调用关系，但没有执行游戏状态、随机数、分支、ASM 或准备画面。单位最终阵容、成长属性、事件触发时机仍需运行时执行；本目录也尚未接入项目的可玩副本。封印之剑、烈火之剑及其他章节尚未完成同等解析。
