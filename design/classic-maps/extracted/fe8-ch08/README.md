# 圣魔之光石·第8章：原始数据提取样例

本目录保留早期美版公开数据版本。现已完成[用户所提供日版 ROM 的直接解析](../fe8j-ch08-rom/README.md)，其中部分单位等级、装备与本目录不同；实际 ROM 的配置请查看新产物。

本样例从 FE8 美版公开反编译仓库的原始地图、地形表、单位定义和事件定义生成。没有用截图颜色推断地形，也没有使用本地 ROM。所有坐标均为左上角起始、零基 `(x,y)`。

- [交互预览](preview.html)：独立 HTML，双击打开；点击格子查看地形、物品和单位；可切换单位组、事件区域及单项地图变化。
- [结构化章节数据](chapter.json)：地形矩阵、图块编号、移动与战斗加成、单位模板、物件、地图变化、原始事件宏及选定脚本。
- [逐格地形 CSV](terrain.csv)：576行，每格一行。
- [地形 PNG](terrain.png)／[SVG](terrain.svg)：用符号和颜色表示地形，不包含攻略标注与单位遮挡。
- [来源与校验值](sources.json)：固定上游提交及29个输入文件的 SHA-256。
- [接入事项](integration-report.json)：与本项目地形、出生点及连通性规则之间的差异。
- [提取工具与命令](../../../../tools/fe8/README.md)。

## 使用边界与接入

这是可追溯的关卡源数据，不是项目当前 `BattleMap` 类型，也没有自动加入副本列表。单位模板保留了入场点与移动终点，未模拟存档、普通/困难难度、随机成长、公共辅助脚本及完整事件运行时。基础地形尚未自动应用开场剧情的地图变化；预览每次只显示选定的一组变化。

原作的27条初始敌军模板超过项目每方最多8个出生点的限制；原作首领站在制压点，而项目要求目标与出生点不重叠。门、宝箱、柱子、可破坏墙与楼梯也需要适配事件或地形规则。原作隔间和门控通路不一定符合项目当前“全部可通行格开场连通”的验证要求。

批量整理其他章节时，可复用来源校验、MAR/地形读取、单位模板及地图变化解析逻辑；章节索引、素材符号、事件脚本和运行时策略需要逐章选择。NDS 的文件系统与数据格式需另建提取流程。
