# 时空诸将数值与地图设计数据

完整方案：[39 时空副本设计](../../docs/39-cross-time-dungeon-design.md)。这些文件没有接入游戏运行时，不会改变玩家存档或共享经典地图。时空副本与固定兑换已获准作为下一步实现，当前尚未完成。

阿波罗已选定并实现个人技能 **光明神射 `lightshot`**，引擎与前端已有支持：交战开场满 HP 且实际用弓时，将既有战技增益后的有效技巧×2；敌我主动、合法反击、勇者连击、追击及战技技巧触发／返还判定均适用。下次交战受伤失效，补满恢复；不改永久属性或射程。命中、必杀与触发概率限制在0～100%，`noCrit` 不变。可选 `personalSkill` 支持持久化覆盖与战斗快照，肖像不会覆写明确指定的个人技能；技能支持不代表阿波罗已可招募。

属性规则为 HP 上限150、其余八项取消99上限；临时有效技巧也不截回99。具体技能边界与数值示例见 [38 §4.5](../../docs/38-cross-time-generals-draft.md#45-阿波罗光明神射-lightshot已定案已实现)。

- [部署图](map-preview.svg)：当前适配地形上的17名将、8出生点、原物件和警戒线。
- `roster.json`：17人职业、个人成长、一级70点招募基础和体格，以及独立的敌方 `enemyBonus`（16人各20点、吕布24点）；招募不带敌方加成。
- `levels.json`：计算输出，区分原固定20级、招募版48级均值／取整、敌方专属加成、普通敌军48级、困难敌军52级及真实升级抽样结果。
- `map-plan.json`：阵容、位置、有限法术／杖次数、分组及副本参数。
- `map-validation.json`：地图SHA、出生点与物件快照、通行性校验结果；不代表已验证战斗平衡。

从仓库根目录复算（Node 24，无新依赖）：

```sh
node design/cross-time/calculate.mjs
node design/cross-time/check-map.mjs
```

前者内置职业／预算／文档一致性校验，并调用当前引擎进行85,000条成长模拟；后者核对25个部署格、现有门墙的静态可达性、全部配装权限／次数，并重新生成SVG。所有写入均限制在本设计目录。
