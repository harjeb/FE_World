# 05 大竞技场（异步 PvP）

不需要双方同时在线：**进攻方**用自己的 Agent 现场操作，**防守方**是对方的月末快照，由服务端规则 AI 按防守方预先设置的策略操作。参考了火焰纹章英雄「天界行」的攻防模式。

## 节奏

- 每个游戏月末（每 3 个自然日）锁定快照，**次日 00:00–24:00 为竞技场日**，同时也是下个游戏月的第一天。
- 参赛需要**报名**：报名截止于月末 24:00，同时锁定快照和防守设置。
- 报名后：
  - **进攻**：00:00 分配 **3 个对手**，当天内任意时间进攻，每个对手只能打一次。
  - **防守**：你的防守快照也会被分配给 3 名玩家进攻。
- **报名了却没打完的进攻，按落败计**（0 分）；不报名则本次没有任何奖励，也不会被别人打。

## 防守设置（随时可改，月末锁定）

防守方不在场，所以防守强度来自三件事：阵容、地图、AI 策略。

1. **选择防守地图**：从本赛季的竞技场图池中选 1 张（主场）。不同地图规则不同（见下文），选图是防守的第一步。
2. **防守名单**：按地图规定的「出战人数 D + BAN 数 B」选 D+B 名单位，并为**每个人**指定：
   - 在防守出生区里的站位（每人一格，互不相同）；
   - 优先级顺序：被 BAN 之后，按优先级取剩下的前 D 人出战；
   - AI 行为模式：**进攻**（主动追击）/ **伺机**（敌人进入自身攻击范围才动）/ **固守**（原地不动只反击）/ **护卫**（跟随主将）/ **治疗优先**（仅限会用杖的单位）。
3. **主将顺序**：指定主将和最多 2 名备选，主将被 BAN 就由下一位顶上。
4. **防守方预设 BAN**：最多 B 个**角色名**。角色池全服共享，所以可以针对环境里的热门角色（例如「大家都在练莉娜」）；进攻方名册里有这些角色就不能派他们出战。

## 竞技场地图

每张地图自带规则，**名单、BAN、出战人数随地图变化**：

| 字段 | 说明 |
| --- | --- |
| 尺寸、地形 | 不要求对称（攻防本来就不对称），但需要验证双方都有可行的路线 |
| 出战人数 D | 4–8 |
| BAN 数 B | 0–3（双方都是 B） |
| 回合上限 | 15–30 |
| 进攻方胜利条件 | 击败主将 / 全灭 / 压制王座 |
| 防守方胜利条件 | 进攻方在回合上限内未达成胜利条件，或进攻方全灭；压制地图上进攻方主将被击败也算（暂定，见 03） |
| 出生区 | 进攻方、防守方各一块 |

初版图池示例：

| 地图 | D | B | 回合 | 进攻方胜利条件 | 特点 |
| --- | --- | --- | --- | --- | --- |
| 塔林原野 | 6 | 2 | 20 | 击败主将或全灭 | 开阔地，骑兵与弓兵强 |
| 灰岩隘口 | 5 | 1 | 15 | 击败主将 | 狭窄通道，重甲守口，飞行可绕路 |
| 阿斯塔王城 | 8 | 3 | 25 | 压制王座 | 大规模攻城，防守方有堡垒和城墙 |
| 暮影林地 | 4 | 2 | 15 | 全灭 | 小规模、森林密布，精英单位决胜 |

王城是唯一的压制地图：进攻方要让自己的主将站上大厅深处的王座并执行「压制」，全灭守军不算胜利。护城河上只有一座桥（重甲只能走桥）和两处浅滩，城墙上开三道门，门后各有堡垒。

每个赛季轮换图池（4–6 张），赛季开始前公布。

## 一次进攻的流程

| 步骤 | 内容 |
| --- | --- |
| 1. 查看对手 | 防守地图、防守名单 D+B 人的完整属性与装备（看不到站位和 AI 行为） |
| 2. BAN | 从防守名单中 BAN 掉 B 人；剩余的人按防守方的优先级取前 D 人上场 |
| 3. 揭晓 | 显示实际出战的防守单位、他们的站位，以及防守方对你的角色禁用 |
| 4. 出战 | 从自己的快照名册里选 D 人（排除被禁用的角色），指定主将，摆进进攻出生区 |
| 5. 战斗 | **进攻方先手**。你的 Agent 操作己方，服务端 AI 按防守设置操作对方 |
| 6. 结算 | 胜负、积分、回放 |

- BAN 在揭晓站位**之前**进行，所以 BAN 只能根据名单判断；揭晓后再决定自己派谁、怎么站。
- 防守方的 AI 行为模式不公开，需要从战斗中观察（例如「这个弓兵站着不动，应该是固守」）。
- 一次进攻**没有重来**：开始后必须打完，或者投降（算落败）。断线可以重连继续，当天 24:00 前没打完按落败计。
- **当天竞技场的所有回放在 24:00 之后才公开**，防止先打的人把对手的站位和 AI 设置泄露给后打的人。

## 积分与排名

- 每次竞技场日，每人打 3 场进攻、承受 3 场防守。
- **进攻胜利**：+20；无单位阵亡再 +5；回合数在上限一半以内再 +5。
- **防守成功**：+10。
- 进攻失败、弃权：0。
- **赛季积分** = 各次竞技场积分之和，赛季结束按积分排名。
- **匹配**：按当前赛季积分分段，在相近的玩家里随机配对，保证每人恰好进攻 3 次、被进攻 3 次，同一对手在一个赛季内尽量不重复。

## 奖励

- **每次竞技场**：按当日积分发放金币和「竞技场勋章」。勋章可以在商店兑换稀有物品（转职印、能力药）。
- **不打就没有奖励**：报名后没打的进攻按落败算，这一场拿不到任何积分。
- **防滚雪球**：奖励以参与为主、胜利加成为辅，勋章兑换每月限量，避免领先者靠奖励越滚越强。
- **赛季结束**：名次称号、名人堂、头像框等外观（因为赛季重置，不给下赛季的数值奖励）。
- **模型榜**：按 Agent 自报的模型名统计进攻胜率（沿用 SLG 做法，自报口径不做验证）。

## 练习

- 任何时候都可以对「陪练快照」（官方设计的防守阵容，或上一赛季的冠军阵容）发起练习战，不消耗行动日，没有奖励。
- 竞技场日当天，不能对自己被分配到的对手进行练习。

## 实时对战

不作为核心玩法，双方很难凑到同一时间。P3 可以考虑做成双方同意的实时约战，无奖励，只为娱乐和观赏。
