## 2. 已确认的资源规则

| 类别 | 普通攻击／反击 | 主动技能 | 恢复方式 |
| --- | --- | --- | --- |
| 物理武器、拳套、短刀 | 不扣耐久，被动概率触发也不额外扣 | 仅明确标注消耗的主动武器战技扣耐久 | 营地铁匠铺维修 |
| 法术书 | 普通施法也扣本书次数；本次确实发动的魔法反击同样扣 | 按该法术／战技列出的本书次数消耗，不能再混扣物理耐久 | 旅馆或食物道具恢复该书次数 |
| 功能／治疗杖 | 按实际使用扣杖次数 | 功能动作使用各自次数 | 杖的补充／维修方案另配置，不默认随法术书免费恢复 |
| 普通药品、食物 | 使用扣物品数量／次数 | 同一命令不重复扣 | 正常商店、生产、任务来源 |
| 不朽盾 | 每名角色最多携带 1 枚，致命时消耗 | 石化期间不接受任何治疗 | 有限获取，不能战中补盾 |

法术资源按**每本书独立剩余施放次数**保存，不改为角色共用法力池。换书、交换、卸下、重新装备、换职、重连不能补满。旅馆恢复和食物恢复须明确选择哪一本／哪些书，不能只改客户端数字。一次实际施放先支付次数，即使未命中也扣；未发生的反击不扣，次数不足不能开始该次施法。

完美锻造确认：一次成功使武器**最大耐久＋10、新成品当前耐久同步＋10**；40／40 → 50／50。每件仅一次，维修不叠加。法术书次数和杖次数不自动获得这项加成；无损耗成品仍是另行设计的稀有配方，不是普通完美的默认结果。

0 耐久的物理武器首稿仍可普通攻击／反击，但不能使用需要耐久的战技；损耗的是战技资源，不把“普攻免费”又改回“无耐久不能普攻”。0 次数法术书不可施法／反击。特殊武器若有独立损坏规则须事先显示。

### 2.1.3 本轮决定与实现

1. **银系／勇者进普通生产（已实现）**：新增 11 条铁匠铺配方（7 条银系、4 条勇者），地区 9 声望 100／250 解锁；输入矿石与木材，分别 14–20 日；银系／勇者可正常出售，不属于唯一武器。
2. **唯一武器绑定（已实现）**：`BOUND_WEAPONS` 覆盖王权剑、神授枪、统率枪，以及挑战塔 A 级以上的 12 件签名武器；`SELL` 在扣库存前拒绝并返回“唯一武器已绑定”，整备页禁用出售按钮并显示“绑定”标签。装备、修理和死亡回收不受影响。
3. **地区声望商店、挑战塔整组装备、经典宝箱银武**：按本轮决定保持现状，不做限购、拆分或替换；它们不是随机掉落，仍受声望、任务一次性或塔层通关限制。后续如做经济与内容平衡，再单独评估。
4. **上限规则**：任务和塔层来源本身都是一次性，当前不会从这些渠道重复获得同一唯一武器；若未来新增唯一武器来源，必须同时登记到 `BOUND_WEAPONS` 并保持每账号每件 1 把。

## 3. 装备字段

| 字段 | 含义／约束 |
| --- | --- |
| `templateId / instanceId` | 模板定义与唯一实物分开；快照和真实资产有来源标记 |
| `type / rank / allowedSpecies` | 武器类型、熟练度、职业和种族共同校验 |
| `might / hit / weight / crit / range` | 威力、命中、重量、必杀、最小／最大射程；单位和取整沿用00 |
| `damageType / effectiveTags` | 力对防或魔对魔防；特效标签不凭名称推断 |
| `durability / maxDurability / durabilityPolicy` | 物理战技耐久与最大值；普通攻击扣除为0 |
| `charges / maxCharges / rechargePolicy` | 法术书或杖剩余次数；每本独立，不与耐久复用字段 |
| `skillGrants / growthGrants / sourceId` | 穿戴技能、成长及来源；卸下失效，同来源不重复计数 |
| `quality / refinementResolved / bound` | 品质、是否已精工、绑定；领取／出售遵守绑定和唯一结果 |
| `price / repairCost / unlock / sourceLimit` | 价格、维修、资格与限量获取，须随目录版本保存 |

重量通过体格抵消后的规则影响攻速；普通盾／饰品采用额外重量时必须计入显示。下文普通护盾和消耗型不朽盾是不同物品，不能因名字都有“盾”就共享保命效果。

## 9. 落地验收

- 按武器实物保存耐久、法术次数、品质、精工与归属；同模板两本书独立消耗，交换／换职不恢复。
- 普攻／反击／概率被动对物理耐久扣0；战技预付固定消耗，未命中也消耗；法术普通施放和实际反击都扣次数，资源不足不能发动。
- 旅馆／食物恢复目标正确且不重复发放；活动外恢复不可绕过年度／连战锁，石化不能接受任何 HP 回复。
- 完美40／40→50／50，重复停止／领取／维修不再＋10；法术书次数不被错误当成武器耐久加10。
- 每人最多1枚不朽盾在购买、转移、开战、年度报名和恢复旧存档时一致校验；多种治疗来源都验证石化禁疗。
- 任一装备的查看、买卖、穿脱、使用、修理、锻造、食物与旅馆恢复均可由人和 Agent 通过同一规则完成。
