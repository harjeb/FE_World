# 40 材料与锻造（现行实现）

本页记录已实现规则，替代旧文档中“药草／矿石／木材三类通用资源”和仅铁器派遣奖励的描述。依据：[materials.ts](../backend/common/game/materials.ts)、[production.ts](../backend/common/game/production.ts)、[expedition.ts](../backend/common/game/expedition.ts)、[dispatch.ts](../backend/common/game/dispatch.ts)、[items.ts](../backend/common/game/items.ts)、[weapons.ts](../backend/common/data/weapons.ts)。装备战斗效果仍见[22](22-equipment-catalog.md)。

## 1. 材料与采集

药草、矿产、木材各 24 种，共 72 种；每类每阶 3 种普通、1 种稀有。种子另算。旧 ID `herb`、`ore`、`wood` 分别保留为止血草、铁矿、白杨木，不把旧库存拆分或兑换。材料目录价 T1–T6 为 80／140／240／380／600／900，稀有为同阶三倍。

采集等级 1／10／20／35／55／75 分别开放 T1–T6，候选为当地栖息且不超过当前阶的所有材料，地区编号本身不提高阶级。每次先独立判定稀有池，再按 `2^阶级 × 主产地系数` 加权抽取一个材料；主产地系数为 2，其他栖息地为 1。当地没有可用稀有材料时回落普通池。结果按 ID 合并数量；独立种子流不消耗战斗 RNG。稀有率指每次采集进入稀有池的概率，不是每个物种的概率。

## 2. 武器主线与配方

剑／枪／斧／弓／拳五类各有木 → 铜 → 铁 → 钢 → 银五阶；材料阶不等于 E–SSS 熟练度，旧武器 ID、属性与使用权限不因归入系列而重算。木／铜沿用扩充目录 ID：剑 `fw_weapon_1/2`、枪 `24/25`、斧 `52/53`、弓 `72/73`、拳 `89/90`（后四组同为 `fw_weapon_` 前缀）；铁拳仍是 `gauntlet`。刃、短刀、兽龙媒介与法术书不属于这五条系列。

每个系列配方均产出 1 件，ID 为 `forge_<wood|copper|iron|steel|silver>_<sword|lance|axe|bow|gauntlet>`：

| 阶 | 输入 | 工期 | 配方声望门槛 |
| --- | --- | ---: | --- |
| 木 | 白杨木 ×3 | 4 日 | 无 |
| 铜 | 铜矿 ×3、白杨木 ×1 | 6 日 | 无 |
| 铁 | 铁矿 ×3、白杨木 ×1 | 8 日 | 无 |
| 钢 | 铁矿 ×4、煤炭 ×2、硬木 ×2 | 12 日 | 无 |
| 银 | 银矿 ×6、硬木 ×3 | 16 日 | 地区 9 声望 100 |

钢由铁矿＋煤炭直接制作，不要求先造铁武器，也没有钢锭中间物品；银必须用银矿，不能用通用铁矿替代。系列配方覆盖同 ID 的旧配方。非系列银刃／银短刀仍用银矿 ×9／×6、硬木 ×3／×2，18／14 日；勇者剑枪斧用精金 ×10、硬木 ×5，弓用精金 ×9、硬木 ×6，均 20 日、地区 9 声望 250。必杀弓／必杀枪／`forge_armorslayer` 用铁矿 ×6、煤炭 ×2、硬木 ×3，保留原工期与声望门槛；后者实际产出 `armorslayer` **破甲枪**，配方显示名为“锻造破甲枪”。

每种材料还有固定用途，不是任意材料自由合成：

- 药草药剂：T1–2 产伤药，T3–4 产解毒药，T5–6 产特效药；普通消耗本种 ×3、稀有 ×1；T2、T4 或稀有产 2 件，其余 1 件；工期 T＋2 日。
- T1–2 矿产：本种普通 ×3／稀有 ×1＋止血草 ×2，4 日，解毒药普通 1／稀有 2 件。T3–6 合金剑：本种普通 ×4／稀有 ×2＋铁矿（T3–4）或银矿（T5–6）×2＋煤炭 ×2＋硬木 ×1，工期 3T 日，依次产钢剑／钢剑／银剑／勇者之剑；相同输入 ID 合并计数。
- 木材弓身：本种普通 ×4／稀有 ×2；T2 加铜矿 ×3，T3–4 加铁矿 ×3，T5–6 加银矿 ×3，T4 另加煤炭 ×2；工期 3T＋2 日，T1–6 依次产木／铜／铁／钢／银／勇者弓。
- 物种配方 T1–2 无声望门槛，T3／4／5／6 默认要求主产地声望 50／100／200／300；矿产与木材的 T5／6 锻造改为地区 9 声望 100／250。恢复杖用黄芪 ×4＋硬木 ×1；护身符用灵叶 ×6＋玉兰 ×1＋香木 ×2，保留地区 5 门槛。

王都常备五种木制起装，材料售止血草、铜矿、白杨木和种子；铜／铁／钢等基础装备另在季度军需轮换池，每季抽 8 种、每种限 3。银系与勇者可生产、可出售；任务／挑战塔绑定武器不因此开放制造或出售。

| 多图副本／远征 | 开始时冻结各图 `3 + 图索引` 次（首图索引 0），普通 12%／困难 18%，每图另加种子 ×1；途中进远征袋，完整通关才带回，撤离／失败作废 |
| 副本首通 | 普通／困难分别记录首通；地区按剑、弓、枪、斧、拳循环选系列，普通阶为采集阶、困难再加一阶，封顶银；另给伤药 2／4、完整料理 1／2。固定宝箱仍单独结算 |
| 后台派遣 | 出发当天地区敌人等级定阶；采集 `max(1, floor(日数/2))` 次、稀有率 4%，种子 `max(1, floor(日数/4))`；至少 5 日才有 25% 种子判定带回 1 件系列武器，按地区上述五类循环、采集阶封顶银，出发时冻结 |
| 地区任务 | 目录固定种子、稀有率 0：短／标准／地区远征／核心分别按等级 1／10／20／35 采集 3／4／6／8 次；原固定装备奖励保留。地区 1 的任务 -1／-2／-3／-7／-9 依次给木／铜／铁／钢／银剑 |
| 主线／伙伴／悬赏／经典远征任务 | 在任务目录中按固定地区、等级与种子生成普通材料，不随领奖时等级重抽；主线每章 5 次、伙伴等级 20 共 5 次、悬赏 3 次；经典三图远征 8 次（fe6/7/8 等级 35，其余 20）。固定装备、补给与任务物品另保留 |

已有 `materialLoot`、`weaponLoot`、`firstClearLoot` 优先，刷新／重连／返程不重抽。缺字段的旧战斗保留原地区三类材料与回合数量公式；旧远征沿用 `stageLoot`（每图单类材料 2＋图索引、种子 1）及旧首通装备表；旧派遣沿用三类材料与铁剑／铁枪／铁斧的旧抽取规则。新配方不改已开工订单冻结的产物；旧武器实例耐久不因材料重命名补满。任务材料是目录固定值，不等同于每个任务都有独立存档奖励快照。

## 4. 种植与生产占位

药草田 2 工位、炼药所 1、铁匠铺 1。`plant_herb` 保留种子 ×1 → 止血草 ×2、20 日。其他普通药草配方为种子 ×T，T2 以上另耗本种 ×1，产本种 ×2，工期 20＋4T 日；声望门槛同物种配方。稀有药草没有种植配方，木材与矿产也不能种植，避免把稀有采集变成药田循环。

播种推进个人日历 1 日；炼药和锻造开工不推进日期，只占用工位。订单按保存的开始日与工期成熟；成熟只变为可领取，不自动发放或重播，未领取仍占工位。配方材料、工期与声望是现行参数，经济平衡仍须结合实际采集与行动日验证。
