# 随机战场与地图生成工具

当前随机野外和随机副本使用生成器 v4：先确定战场布局、双方编队与人数配置，再选择参战单位。经典地图保留原作部署区与出战限制。地图工具可以独立运行，不依赖数据库或第三方 npm 包。

## 正式遭遇配置

| 布局 | 尺寸 | 普通出战上限 | 困难出战上限 | 地区1–4普通／困难敌军 |
| --- | --- | --- | --- | --- |
| 交错遭遇 `skirmish` | 18×18 | 4 | 6 | 3／5 |
| 分进合击 `pincer` | 24×22 | 6 | 8 | 5／8 |
| 分散据点 `convergence` | 24×24 | 8 | 8 | 6／9 |

地区5–12的普通基础敌军再增加2人，困难在基础人数上增加50%并向上取整。敌军规模独立于本次所选人数：少带人不会同步减少敌军。困难敌军等级、能力和装备强化继续按[03](03-combat.md)执行，不重复叠加人数。

同一账号、日期、地区和活动的战场配置固定，刷新、换队和切换难度不会重抽布局；实际战斗随机数使用另一份服务端种子。`GET_TODAY.sortieRegions[].encounters`及`dungeonEncounters`给出两档配置，`PREVIEW_ACTION.encounter.map`返回实际地形、出生点、目标与己方分组。网页在出发前显示这些信息，Agent可读取相同数据。名单超额、重复或不可用时拒绝操作，不再静默截断。随机远征保存开局配置，后续图使用相同上限和敌军规模，以图号派生地图种子。

## 编队与路线

- **交错遭遇**：双方错位展开，出生点不再固定为左右两列。
- **分进合击**：己方分成两队，中间保留不可穿越的隔墙，在较远的通道会合。正式24×22地图测试要求任意两组己方出生点的最短地面路线至少25格；双方同时推进也需要数回合，不能开局直接合队。
- **分散据点**：己方与敌方分布在不同方向，通过据点和通道争夺中央区域。

出生点按组交错分配，前两名队员就会分到两路，敌军前几个位置也分布到不同小队。布局整体按种子翻转、转置并调整位置，地形和目标一起转换。隔墙属于布局约束，连通性修复必须绕开；不会为了修路把两队之间的墙直接凿穿。

每个初始出生点对步行、重甲、骑乘、飞行均可达，并有未被初始单位占据的相邻出口。完整地图保存到战斗快照，刷新、重连和回放不会重新摆兵；旧战斗不重排。

## 快速使用

需要 Node.js 22.18+，原生运行 TypeScript。

```bash
# 自动选布局，终端预览
node tools/mapgen/cli.ts --seed example

# 指定分队布局与不同的双方人数
node tools/mapgen/cli.ts --layout pincer --width 24 --height 22 --units 6 --enemies 8 --seed valley-02

# 导出SVG或JSON；--out拒绝覆盖已有文件
node tools/mapgen/cli.ts --layout convergence --theme forest --width 24 --seed forest-01 --format svg --out forest.svg
node tools/mapgen/cli.ts --layout pincer --width 24 --height 22 --seed valley-02 --format json --out valley.json

# 验证已有地图
node tools/mapgen/cli.ts --check valley.json

# 连通性、布局与工具测试
node --test tools/mapgen/mapgen.test.ts backend/common/maps/layouts.test.ts
```

工具允许宽高10–64、己方1–8个位置、敌方1–16个位置；`--enemies`省略时沿用`--units`。这些是工具边界，正式游戏使用上表配置。小于20格的窄小地图无法容纳长距离隔墙时使用紧凑部署。种子为1–200字符。`--check`不与生成参数混用。

## 地形主题

| 参数 | 地形特征 |
| --- | --- |
| `grassland` | 平原、成片树林、局部山地与河道 |
| `forest` | 森林与林间空地 |
| `mountain` | 山地、谷道、树林与河道 |
| `city` | 建筑街区与石地板路网 |
| `town` | 房屋、十字道路与空地 |
| `palace` | 室内墙壁、房间与常开走廊 |
| `riverlands` | 大河浅洲：宽河、沙洲和桥；瓦恩要塞野图池 |
| `lakeland` | 湖心群岛：湖面、岛屿和桥；莱斯米尔湖镇野图池 |

主题决定自然地形或建筑，编队布局决定行军方向与分队路线。两种大水面主题保留地区原有遭遇选择，20×20代表种子在修路后仍保留至少25%水域。冬季转换由战斗创建层完成：草地变雪地、水域和浅滩变冰面。生成器不读取日历。

## 生成与验证

1. 按独立种子选择布局、方向、分组、位置与受保护的隔墙。
2. 生成主题地形并放置隔墙，清理部署区及目标周围。
3. 在不穿过受保护隔墙的前提下铺设通路，水域上铺桥。
4. 连接四类移动方式的孤立区域，然后进行独立连通性校验。

校验要求所有可进入格、出生点与王座连通，出生点互不重叠、目标不与出生点重合，每个位置保留出口。非法尺寸、布局、地形、位置和人数直接报错。修复每次连接一个不可达区域，不使用无限随机重试。

连通性不保证战斗必胜：敌军堵路、重甲碎冰、动态占位和实际战力不在静态检查范围内。普通野外仍有20回合截止；分队节奏和全局战斗平衡需要后续试玩。

相同版本、种子、主题、布局、尺寸和双方人数产生相同地图。新地图为`generatorVersion: 4`；已有v3 JSON仍可读取校验，但重新生成会得到v4布局。历史示例SVG/JSON保留其旧版快照，不作为新部署规则。代码不使用时钟或`Math.random`，只有CLI省略种子时生成新种子。

## 代码与测试

| 文件 | 职责 |
| --- | --- |
| `backend/common/game/encounters.ts` | 正式遭遇类型、地图／难度名额、独立敌军人数与稳定种子 |
| `backend/common/maps/layouts.ts` | 编队几何、分组、隔墙与整体变换 |

| `tools/mapgen/cli.ts`、`render.ts` | CLI、ASCII和SVG预览 |

测试包含8主题×100种子×4尺寸的3,200张地图、最大和狭长尺寸、四类移动连通性、分队最短路径、种子变化、不同敌我人数、初始出口、水面比例、旧版读取、非法输入及文件覆盖保护。实际战斗接口另检查预览一致性、名单拒绝时无资源变化、独立敌军规模与远征继承。
