# 20 · 地区任务、战斗目标与声望

更新：2026-10-18。当前日历为一年500日、一季125日、八年4000日；任务按逐图出战人数与敌军等级上限执行，不采用年度经验硬额度。

十二地区现在各有九项一次性本地任务，共500声望；专注一地、首次全部成功时，最快5行动日达到100、16日达到250、40日达到500。共有114项公开定义（108项本地任务＋6个保留经典副本）；旧60项经典单图和18项短经典副本共78项定义仅保留查找与续档，归档后拒绝新开，旧进行中／待领奖记录仍列出。声望路线的速度以行动日比较，实际操作时间与难度仍需人工试玩记录。

地区探索度与声望、`clearedRegions`独立，十二地区以`flags.regionExploration`持久化0～100进度，新账号均为0，累计最多100。普通随机野外遭遇战胜利+3、单图任务完成+5；每个副本（含多图任务）仅首次完整通关+20，不计中间图或重复副本，不叠加任务5点。单独领奖、失败、撤退、扫荡和后台派遣均+0；首次胜利仍按原规则开放战斗功能与扫荡。缺失探索度字段的旧档惰性初始化，仅此前已讨伐地区设100，其余为0；既有探索度不再回填，已开通地区访问权保留。世界、任务、随机野外准备与副本准备页显示探索条。

## 1. 范围与进度

声望永久保留、各地独立、不按年清零，购买商品只扣金币。失败不发首次奖励，也不默认扣声望；接取、查看、领奖不推进日期，实际入图才扣一次。玩家可跨年或跨地经营，无须刷满十二地区才能完成八章主线。

所有地区通过一次性任务到达盟友，不提供可重复委托或现实时间恢复。地区任务预算从开通当地路线后开始计；新档自由选择1～4号起始路线，之后须将已开通地区探索至100才可选择其相邻新路线，已开通地区仍可访问，前置地图进度单独计算，见[36](36-playtest-feedback.md)。经典关卡保留金币、地图战利品、首次完成记录与连战内容，新领取的奖励不再增加地区声望，避免只分配在希尔瓦林地／托尔加丘陵／莱斯米尔湖镇的经典地图加快三地声望。旧档已经获得的声望（含超过500的数值）和领奖记录保留，不回扣、不补发。

## 2. 战斗目标与结算

**连战首通固定奖励（目录61）：**12个地区三图副本、48个地区任务远征和6个保留经典副本共用完整通关结算。普通／困难各有一次固定首通礼包：普通为一件地区优质装备、1件能力成长药、2份特效药、2份完整料理与1枚转职印；困难为更强的地区装备、2件同种成长药、4份特效药、3份完整料理与2枚转职印。装备按`dungeonFirstClearLoot`固定配置，以必杀、银系、高阶媒介和高级治疗装备为普通奖励，困难以勇者系列、高阶龙息与全体治疗装备为主；不按出发等级降低品质，不抽概率，首领携带装备也不按概率掉落。地区主副本按地区、任务远征／经典副本按任务ID分别记录两档资格；仅完整通关自动入库，中间图不发，失败／撤离作废未带回掉落。手动任务奖励和首通探索度仍跨难度只计一次，普通单图任务仍仅普通且不可重接。旧完成记录只抑制对应难度补发；旧`questsDone`仅作为普通档回退，困难完成独立判断。困难必须先普通完整通关同一内容。新远征出发时冻结礼包，更新前已出发的远征保留原有礼包；历史首通不重发。

副本入口的12条地区路线与6条固定路线均以当地地理或地图场景命名，60张经典地图的显示名也统一重命名，不附原作名或章节编号。路线条目只显示名称与副本等级，选中时按首图预览敌军的平均等级显示（保留一位小数），未取得预览时用≈标记地区基准估计；耗时只显示总日数与到达日期。

| 类型 | 胜利条件 | 失败／部分完成规则 |
| --- | --- | --- |
| 讨伐 | 击败指定目标或全灭 | 依地图明确目标；投降不发通关奖励 |
| 占领 | 存活己方在目标点执行占领行动 | 单纯走过不算；多目标须全部完成 |
| 护送 | 指定NPC存活并到达撤离格 | 必须保护的NPC阵亡即失败 |
| 抢物资 | 至少1箱由携带者成功撤离 | 1箱即可结束，额外箱子增加当地物资，基础奖励只领一次 |
| 防守 | 指定设施／保护对象存活到指定回合 | 设施失守即失败，不要求全灭 |
| 地区远征 | 固定名单连续完成三图 | 仅整次通关后标记任务完成并开放领奖，失败／撤退作废未带回掉落 |

撤离是地图动作，不等于全军撤退；成功撤离者不算战死。护送NPC沿保存的固定路线点前进，网页／Agent能读取路线与下一步目标，不占玩家名册、不消耗玩家药品。

每人最多搬1箱，不占装备栏、不额外减移动。携带者阵亡后箱子落在其位置；存活者可拾取。撤离后不能返场；结算只读取已撤出的箱子，不能由客户端报告代替。若纳入连续副本，物资先入远征袋，仍需整本完成。

地区远征前两张生成图读取`stageGoals`：偶数地区为占领→全灭，奇数地区为全灭→占领；第三图使用冻结经典场景的目标。旧远征没有`stages`时继续原三图目标。逐图消耗3／3／2日，图间回复最大HP的25%，不自动满血；HP、装备和独立剩余次数跨图保留。任务配置、战斗目标和预告使用同一来源。

## 3. 日期、经验与部署

| 规模 | 行动日 | 默认敌军等级上限 |
| --- | ---: | ---: |
| 短任务 | 1 | 30 |
| 标准任务 | 2 | 50 |
| 三图地区远征 | 3／3／2，共8 | 80 |

逐图`enemyLevelCap`和`maxUnits`可覆盖默认值，经典图读取adaptation；名册上限18，容纳主力与约10名替补。敌军随出发日期定级后受该图上限限制，不读取己方等级追涨；远征冻结入口基准，后图仍受同一任务上限约束。失败、撤离或断线不退已支付日期，重连不重复扣费。

任务额外奖励只给金币、物资、装备和声望，不额外发“任务经验”。交战、击杀与等级差收益遵循[19](19-experience-time-balance.md)，高出敌人5级及以上时击杀只得1经验，首领相同；公共池、治疗与派遣不能绕过等级差抑制。普通竞技场不发等级经验或地区声望。

## 5. 装备、资源与人物

声望提供购买或生产资格，金币／材料承担消费；旧地区商店的门槛、价格、库存和配方保持现有配置，不因补齐路线撤销已开放资格。新增核心链按当地主题发药草、木材、矿石或种子，不额外投放传承石、轮回核心或不朽盾。

原三地终章仍是账号传承的一次性解锁来源：`gw9`给成长传承石、`ih9`给数值传承石、`wl9`给轮回核心，三者各有1枚不朽盾。配置通过`unlocksLegacy`显式标记，不能因新ID也以9结尾而扩大来源。短弓、净化剑、三本限量书及教材、地区专属武器仍经原任务发放，详见[22](22-equipment-catalog.md)、[27](27-fortunes-weave-equipment-magic.md)。

固定人物雷恩／伊格／米拉仍经原三地远征领取。人物身份唯一，已拥有／死亡／解雇后不能重复领取；名册满时保留整份奖励待领，不吞人物、不超出上限。领取后显示`RECRUIT_LINES`台词。

新账号从D0、1级主角开始，通过`COMPLETE_SETUP`自捏主角并自选两名非剧情奖励同伴，只能完成一次；已有多人旧档保留原名册。普通游历、酒馆与紧急补员使用随机人物生成器，与固定人物任务分开。

## 6. 验证与实测边界

运行`node --test backend/common/game/quests.test.ts backend/api/quests.test.ts backend/api/classic.test.ts backend/api/equipment-sources.test.ts`（Node.js 22.18+）。验证包括：

- 穷举十二地所有合法任务完成集合，100／250／500档最短行动日均为5／16／40，九项本地任务均可完成；全部商店声望门槛可达。
- 原三任务旧进度继续解锁新支线和终章，领奖持久化、同一命令重试只支付一次；旧专属实物不补发。
- 新核心远征逐图读取目标、逐图支付3／3／2日，仅第三图胜利后可领80声望。
- 经典任务仍发金币和战利品，已获得的旧声望保留；新终章不扩大稀缺物品或传承解锁来源。
- 占领、护送、箱子掉落／拾取／撤离、永久死亡、满员待领、出战锁与经典副本继续走原引擎和事务。

行动日预算相同不代表实际操作时间、各地区难度或经济平衡已验收。多人压测与40–60小时人工试玩另记实际执行日期、环境、人数／时长、结果与遗留问题，见[首版交付](28-release-readiness.md)。
