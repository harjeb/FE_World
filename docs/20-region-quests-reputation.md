# 20 · 地区任务、战斗目标与声望

状态：已确认采用“地区任务→资源/装备/当地声望→解锁装备和人物任务”的方向。本文给出首版内容及数值方案，具体阈值待试玩校准。

**已实现（首版）：**地区任务与声望后端、`GET_QUESTS` / `START_QUEST` / `CLAIM_QUEST_REWARD` / `BUY_QUEST_ITEM`、坚守（defend）与撤离（escape）、抢物资（gather）、护送（escort）战斗目标，以及网页的「任务」页。绿林、铁丘、水乡各 6 个首次任务；短/标准 1/2 日、地区远征 6 日（三图各 2 日，接现有大副本流程，完成整本才标记任务）。声望四档、声望商店（金币购买，不扣声望）、固定人物加入（地区远征完成后加入，已拥有则跳过）、任务奖励与声望分开领取、重复请求不重发；成功撤离的单位不算战死。

**尚未实现：**可重复委托（用户定案：不做）、声望配方解锁（生产配方仍不按声望开放）、固定人物具体归属与对白、地区远征各图不同目标（现在三图都是 boss）、奖励预览的事务化完整校验（当前靠单写者同步提交与幂等键，未单独加回滚测试）。已实现的日期敌军与经验限制见[19](19-experience-time-balance.md)。

## 1. 目的与范围

一年120日要让玩家持续作出选择，而非为消耗日期重复杀主将。任务接入现有战斗、副本、物资、人物及个人日历；不再建立第二套战斗引擎或重复经验系统。

首版做绿林、铁丘、水乡三地，每地6个首次任务、2种可重复委托；先验证占领、护送和资源撤离，再扩展到十二地区。每年的任务战斗替换原本的培养地图，不在“8张标准培养图”之外强加一整套必做任务。普通竞技场仍不发等级经验或公共经验，不产地区声望。

玩家可选择重点经营地区，无须十二地刷满才能完成八章主线。声望永久保留、不按年清零、不在购买时扣除；任务失败不会默认扣声望。

## 2. 战斗目标与结算

| 类型 | 胜利条件 | 失败/部分完成规则 |
|---|---|---|
| 讨伐 | 击败指定目标或全灭 | 依地图明确目标；投降不发通关奖励 |
| 占领 | 存活己方在目标点执行占领行动 | 单纯走过不算；多目标须全部完成 |
| 护送/救援 | 指定NPC存活并到达撤离格，执行撤离 | 必须保护的NPC阵亡即失败；额外救援人数影响可选奖励 |
| 争夺物资 | 获得至少1箱并由携带者成功撤离 | 1箱即可完成基础目标，额外箱子增加物资；地上或敌方持有的不结算 |
| 防守 | 指定设施/保护对象存活到第N回合结束 | 设施失守即失败；不要求全灭 |
| 地区远征 | 固定名单连续完成三图 | 每图目标可不同；普通远征掉落仍需整本完成才能带回 |

撤离是地图动作和目标结果，不等同于现有“全军撤退”。护送NPC由脚本沿预告路线移动，玩家能看到下一步目标；NPC不占玩家名册、不永久入队，不偷用玩家药品。先采用固定路线，避免首版依赖复杂NPC决策。

抢物资首版每个携带者最多1箱，携带箱子不占武器/药品栏、不额外减移动。携带者阵亡，箱子掉在其位置，可由其他存活者拾取；撤离后该角色离开战场，不能返场刷取。战斗结束时只结算已撤离箱子，不能从背包数量直接推算奖励。后续增加搬运负担必须在出征前显示。

资源任务是明确的“带回多少算多少”例外：1箱达成基础目标后允许结束并结算；没有一箱撤出即失败。基础声望一次，三箱不能领三次。若放进连续副本，箱子先入远征袋，仍遵循完整通关才带回的规则，界面须明确说明。

三图远征首版目标：第 1 图探路（压制指定点）、第 2 图消耗战（全灭敌军）、第 3 图首领战（击败守将）。前图结果可提供后图一次补给机会，不自动满血；相关收益必须预先写明。后期16人关卡采用分队护送、守点和多方向争夺，不只增加敌方人数。

## 3. 日期与经验

| 规模 | 消耗日期 | 说明 |
|---|---:|---|
| 短任务 | 1日 | 小地图、少量敌人，适合填补零碎日期 |
| 标准任务 | 2日 | 完整占领／护送／防守 |
| 三图远征 | 每图2日，共6日 | 三图连续 |

**用户定案（修订）：**任务只带 1–2 天耗时，因此一年 120 天可以做的战斗图远不止 8 张（不再沿用 docs/19 的“每年约 8 图”）。短任务地图、敌人数、操作时间和个人/公共经验都按小规模设计；接取、查看、领取奖励不推进日期，实际入图时支付一次。接取不锁敌军等级；入图按当日日期锁定，远征锁入口等级。

因为每年战斗次数大幅增加，docs/19 的年度经验预算（每图 6G 通关等）不再直接适用：要么下调每张图的通关／公共经验，要么把预算改成“每年总量上限”，否则等级会重新涨太快。具体口径待定，未实装。

任务额外奖励只给金币、物资、装备和声望，**不再加一份“任务经验”**。战斗经验沿用共用结算，高出敌人5级及以上时击杀只得1（首领同样），无伤未击杀0。未来通关/公共经验接入时必须一起防止高等级刷低级图绕过限制，详见19。

进入任务前展示日期变化、敌方等级、胜败目标、最低奖励、可选奖励以及永久死亡风险。提前跨到下一年不会重算已进入活动的敌军或奖励。

## 4. 声望档位与解锁

| 声望 | 关系 | 解锁 |
|---|---|---|
| 0 | 陌生 | 基础任务、普通交易 |
| 100 | 熟悉 | 特产供应、进阶委托 |
| 250 | 信任 | 地区装备/配方、特有人物的加入任务 |
| 500 | 盟友 | 招牌装备资格、地区核心任务结局 |

具体声望数值以任务配置为准，首版基准：短任务首次20，标准首次40，远征首次完整通关100；重复短委托5、标准委托10。重复经验和物资仍按实际战斗与任务规则结算，不重复发首次奖。

**不能只刷简单委托解锁终盘：**普通重复委托仅在声望低于250时提高声望，封顶250；500档还要求当地核心任务完成。高阶一次性任务承接后续声望预算，不采用每日次数或现实时间恢复。

每地初始6任务组成：2短×20 + 3标准×40 + 1远征×100 = 260声望，耗时8+24+24=56日，折算7张标准图。无需额外刷重复委托即可达到信任。地区的三项后续重要任务可各给80声望，累计500；其中最后一项是核心任务。后续任务属于扩展内容，首版若未提供，500档必须清楚标记尚未开放，不能让玩家无目标刷到上限。

56日是专注经营一地的路线，并非每年三地各做56日。玩家可以跨年推进或三地择其一；声望任务不会要求当年全部完成。

## 5. 装备、资源与人物

声望给资格，金币/材料承担消费。建议同档任务金币和材料沿用普通出征预算；首次装备作为这份任务奖励中的明确条目，而非基础奖励之外无条件再发一套。完成后奖励页逐项列出，不用隐藏随机性替代目标感。

生产配方也按声望解锁（`Recipe.requires`）：绿林/铁丘/水乡各有一到两个声望配方（必杀弓/必杀枪、破甲剑、恢复杖、魔防符），开工时校验声望，未达标返回阻挡原因；声望不足不消耗材料。

| 地区 | 资源/装备特色 | 人物与任务方向 |
|---|---|---|
| 绿林 | 木材、弓、轻装、应对飞行敌人 | 猎手、林地救援、截取物资 |
| 铁丘 | 矿石、重甲、破甲武器、锻造配方 | 守卫、矿道防守、据点占领 |
| 水乡 | 药草、恢复品、治疗及补给装备 | 医者、护送伤员、保卫渡口 |
| 风崖（后续） | 飞行装备、轻金属、机动用途 | 飞行伙伴、高地争夺 |
| 兽岭（后续） | 兽族装备和材料 | 兽人伙伴、族群援助 |
| 龙谷（后续） | 龙族装备和材料、抗魔用途 | 龙人伙伴、遗迹守护 |

同声望不意味着所有地区发相同强度的数值装备，强调用途差异。商店每件装备同时要求声望、地区任务阶段，以及相应装备开放进度；只靠早期重复委托不能买到终盘武器。现有武器/道具目录没有的装备能力，不能仅写文案就当作已生效。

固定角色：信任档开放加入任务，任务完成后领取角色；角色自身身份唯一，不能重复领取、解雇后重领或死亡后重领。原有12名预设人物的具体地区归属、加入时点与数值另配表，不在此随意分配。名册满时保留待加入状态，不因满员失去人物，也不强制超出名册上限（领取时先完整校验：满员直接报错、不消耗领取资格）。加入时附一句台词（`RECRUIT_LINES`）。

### 5.1 开局名册

新账号开局先自捏神主角（姓名/性别/职业/形象/成长类型/培养倾向/九属性分配），再从剩余预设人物中自选两名同伴，排除剧情奖励人物（雷恩/伊格/米拉），恰好两人、不能重复，且只能完成一次（op `COMPLETE_SETUP`，同一事务写入）。这样预设人物不再开局全发，地区远征奖励的固定人物加入才有意义。已有多人的老存档不再要求重选；演示测试用 `backend/api/test-support.ts` 补全整套名册。

地区普通招募与固定人物任务分开。普通招募按地区允许职业池再应用生成器权重；兽岭/龙谷可以开放当地稀有种族机会。招募等级越高，职业阶段越高（Lv1–9 初级、10–19 二级、20–29 三级、30+ 四级，`recruitClass`），上级职业同样允许，数值以该职业 1 级基础值推导。固定人物不混进随机池，也不以反复刷新复制身份。

## 6. 首版三地任务样例

名称是制作占位，角色和对白另行编写。每地6个任务依次开放，熟悉档用于中段任务的资格；前3项声望20+40+40=100，避免前置锁死。

| 顺序/规模 | 绿林 | 铁丘 | 水乡 |
|---|---|---|---|
| 1 短，20声望 | 林道侦察：击败哨兵 | 矿道清障：讨伐 | 渡口求援：救援 |
| 2 标准，40 | 护送采集队撤离 | 占领矿道入口 | 护送伤员撤离 |
| 3 标准，40 | 抢回被截木材 | 防守运输站 | 保卫药草田 |
| 4 短，20 | 接应落单猎手 | 撤离被困矿工 | 抢救补给箱 |
| 5 标准，40 | 防守林间营地 | 抢运矿石 | 占领被封渡口 |
| 6 远征，100 | 夺入口→护补给→讨伐 | 占矿场→守运输→讨伐 | 救援→守渡口→撤离 |

每地两种重复委托复用已有地图和目标，但替换部署/路线/物资位置。首版不制造大量同名换皮任务。至少每两张相邻任务地图有目标或战术结构的变化。

## 7. 实现约束与验收（尚未实现）

任务定义包含地区、前置任务/声望、地图目标、日期、基础与可选奖励、首次/重复标记。玩家保存任务状态、唯一完成/领奖记录、各地声望、固定角色领取记录；战斗保存NPC、物资箱、撤离状态和目标进度。重连读取保存状态，不能靠客户端报告“已撤离”或“已拿三箱”领奖。

复用现有活动锁、战斗持久化和命令幂等。首次奖励、声望、库存变化和完成标记在同一事务结算；重复请求返回原结果，不重复发奖。失败、撤离、断线不退已付日期；断线不自动判败。奖励无法入库时保留待领取，不能吞掉资源或无限重复选择随机结果。

实施顺序：先扩展战斗目标和测试，再做任务进度/声望结算，然后地区面板与奖励预览，最后配置三地内容。不存在的新任务op不先发布到Agent协议；协议和网页在功能可用时一起接线。

验收至少覆盖：

- 不杀主将也能按占领/撤离目标获胜；NPC死亡正确判败。
- 箱子掉落、拾取、撤离及断线重连保持一致，未带出箱子不入库。
- 同次任务并发领奖只加一次金币、道具和声望。
- 重复委托不能越过250上限，也不能解锁未完成核心任务的盟友奖励。
- 固定人物满员待领、解雇/死亡不重领。
- 任务的4/8/24日只扣一次，经验不重复叠加；普通竞技场依然0等级经验。
- 三地各6任务可以顺利达到260声望；没有必须先到250才能接到前置任务的循环。

第一年试玩重点看是否有明确目标、第三年看配方和职业变化、第七年看16人分队。日期能花完不代表内容足够：记录被迫等待、连续同打法通关、真实耗时和资源缺口，再校准声望及奖励。
