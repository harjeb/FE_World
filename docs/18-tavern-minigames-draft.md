# 18 酒馆小游戏首版设计（待实现）

更新日期：2026-10-17。摇盅猜大小和青蛙赛跑已由用户确认纳入首版，玩家可选择不玩；以下局数、下注额、返还倍率与时长仍是待校准首稿，不是最终经济数值。当前没有可玩逻辑、接口或UI，所有人类操作须有Agent 1:1入口。

## 定位与共同规则

- 酒馆解锁后可参与，使用游戏内金币，不涉及充值兑换。可以完全跳过，不影响主线、年度大竞技场、角色招募或职业解锁。
- 正式局下注消耗金币，胜利获得金币返还；不产人物经验、精通、成长率、永久能力药、稀有材料或专属强力装备。免费练习可反复玩，收益为0。
- 单局不推进个人行动日，演出暂按十几秒至几十秒设计，可以加速或跳过；结果不受观看时长影响。不给主线设置小游戏胜场或等待时长门槛。
- 每局先选20／50／100金币中的一档；确认前同时显示押对的总返还与净收益，下注后不能改押、追加或取消。
- 每个个人游戏季度暂限6局正式局，两种游戏和所有地区酒馆共用额度。季度按本账号行动日计算，与现实月榜、现实月职业购买额度分开；切换酒馆、重连、现实跨月均不刷新。
- 金币不足不能开局，不借贷、不自动抵押装备。进行中的正式战斗、连续副本及年度赛事不开放下注；后台派遣、生产继续按已有规则运行。
- 幸运、魅力、等级、种族及装备不改变结果或赔率，沿用已定属性职能。地区先改变酒馆外观、蛙的名字和简短见闻，不提高中奖率。

## 摇盅猜大小

1. 选择“大”或“小”和下注额，查看返还规则后确认。
2. 服务端掷三颗公平六面骰；点数总和4–10为小、11–17为大。
3. 三颗点数完全相同为“三同点”，无论总和大小，押大、押小均输；这条在下注前显示。
4. 押对返还本金的2倍，**包含本金**；押错或三同点返还0。摇盅／开盅演出暂定10–20秒，可直接查看结果。

例：押50金币，确认时扣50；猜对入账100，净赚50；猜错或三同点入账0，净亏50。

三颗骰子共216个等概率结果，大小各有105个赢的结果，三同点共6个。单边胜率105／216≈48.61%，按2倍含本金返还计算，长期期望约亏下注额的2.78%。不按“50%胜率再额外判三同点”重复计算。

## 青蛙赛跑

1. 四只青蛙同场，玩家选择一只获胜者和下注额。首稿四只夺冠概率均为25%，下注前显示。
2. 青蛙用不同名字、颜色与跳跃风格表现个性；首稿这些差异仅用于演出，不暗示未公布的速度优势。
3. 服务端公平生成四只青蛙的完整名次，保存后播放20–40秒赛跑，可加速或跳过。赛道进度与最终名次必须一致，显示中的领先不额外触发投注。
4. 押中冠军返还本金的3.8倍，**包含本金**；未押中返还0。首稿没有并列、安慰奖或临场追加投注。

例：押50金币，押中入账190，净赚140；未押中净亏50。20／50／100三档对应76／190／380金币总返还，均是整数，无取整差异。

按25%胜率计算，长期期望约亏下注额的5%。名称和跳法可以每季换一批，但不能通过刷新名单、换酒馆或重开演出改变已保存赛果。

## 经济与节奏校准

| 项目 | 摇盅猜大小 | 青蛙赛跑 |
| --- | ---: | ---: |
| 单局下注候选 | 20／50／100金 | 20／50／100金 |
| 押中总返还倍率（含本金） | 2倍 | 3.8倍 |
| 押中概率 | 105／216 | 1／4 |
| 长期期望净收益／下注额 | −2.78% | −5% |
| 个人行动日 | 0日 | 0日 |
| 正式局额度 | 每个人游戏季度合计6局，两种游戏共用 | 同左 |

现行一年四季、八年32季，最多192局正式局；若全部押100金币，八年总投注为19,200金币。全部玩猜大小的期望净损失约533金币，全部玩赛跑约960金币；连续失败时实际损失会更大，不能把均值写成保底。以上不代表完整八年经济已平衡，仍需和招募、修理、生产、职业购买、派遣一同测算。

金币返还用于短期起伏与娱乐，不作为稳定收入来源；长期获取资源仍以战斗、探索和生产为主。首稿不额外添加材料奖池、每日签到、连胜成长奖励或可出售纪念物，避免小奖励反而成为额外经济入口。普通玩法和免费练习不因正式局额度用完而关闭。

部分酒馆可在首次体验后增加一两句见闻，与物品说明共同透露大竞技场、神与邪恶的背景；不要求下注、获胜或玩满指定局数才能看关键故事。小游戏不单独抬高40–60小时目标，后续实测再分配可选活动时间预算。

## 后端设计候选

以下是待实现方案，不是当前可调用协议。

- 规则集中配置并版本化：下注档位、季度共享局数、三同点判定、倍率、蛙数量。倍率用整数分子／分母表达，返还必须整除，不使用浮点金币。
- 未来读取入口提供本季度剩余局数、玩法、赔率和下注预览。开始入口只接收游戏类型、合法选项、下注档位与幂等命令标识，不接收客户端的骰子点数、名次或“我赢了”。
- 确认下注时，在同一事务中校验金币／额度／活动占用，扣金币、占一次额度、生成并保存赛果、入账返还及记录收据。成功返回时已结算，动画只重放保存结果，不另设“看完动画才能领奖”的二次结算。
- 赛果采用服务端安全随机源；不得仅用公开日期、玩家编号或客户端随机数决定。记录包含玩家、游戏、个人季度键、规则版本、下注选项、金额、骰子／完整名次、总返还、净收益及演出所需数据。
- 同一幂等命令重试返回同一局；换负载重用命令标识须拒绝。并发扣款／额度使用玩家状态锁及事务约束，不能同时花最后一笔金币或最后一局额度。
- 断线后读取同一收据恢复；跳过、退出、重新播放和更换客户端不退注、不重复派奖。失败事务不留下半扣款或半占额度；不新增UI或真实接口，直到实现阶段再接入。

## 待实现时的验收项

1. 穷举216种骰子结果，大小各赢105种，三同点6种；总返还和净收益正确。
2. 四蛙冠军分布符合均匀生成规则，完整名次唯一；所有演出路径与保存名次一致。
3. 两种游戏共用每个人季度6局，同季换酒馆、重连不刷新；个人季度变化才产生新额度。
4. 重复请求、并发下注、断线和跳过演出均只扣款／计局／派奖一次；无足够金币时没有任何扣款或额度消耗。
5. 角色属性不改赔率，小游戏不发经验／精通，不推进个人日历，也不阻挡主线和正常招募。
