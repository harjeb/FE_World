# AgentTactics 游戏设计方案（玩法评审版）

> 本文是游戏性设计的统一阅读与修改入口，整合原 01–05、09 的玩法内容及后续讨论。不包含接口、架构、地图生成算法、工具命令或开发进度。
> **已确认方向**表示已认可的核心选择；**当前草案**表示保留供评审的玩法，数值不等于最终定案；**待定／建议**不能当作已确认规则。
> 旧文档保留作为历史资料和数值参考；冲突处以本文明确标注的方向为准。现有原型的行为不反过来决定正式玩法。

## 1. 游戏定位

**已确认方向**：原创火纹式回合制战棋页游，以永久军团养成、PvE 冒险和高难 AI 挑战为主，其他玩家的防守快照作为辅助 PvP 内容。

玩家可以亲自操作，也可以交给自己的 AI Agent。两者遵守相同的战斗、成长和资源规则。

核心体验：

- 培养有个性、有长短板的角色，而不是最终人人全属性拉满。
- 在地形、兵种、武器与行动顺序之间作出战术选择。
- 正式冒险有永久死亡风险，保命道具和撤退构成真实取舍。
- 角色可能离开，但军团历史、收藏和有限培养成果长期留下。
- 长期目标来自新任务、强敌、阵容变化和精英 AI，不靠周期清空养成。

游戏名称、世界观和角色故事尚未定稿；角色、名称与美术采用原创内容。

## 2. 核心循环与长期保留

```text
招募 → 培养与转职 → 装备整备 → 选择关卡与风险 → 正式出征
                                         ├─ 存活：获得经验与资源，继续挑战
                                         ├─ 死亡：纪念名册 → 有限遗产 → 新人接续
                                         └─ 撤退：保住仍存活者，承担结算损失

存活角色可选择一次轮回，重新培养；正常退役作为可选传承渠道待确认。
军团之外：研究阵容、练习、观战回放、快照竞技场。
```

**已确认方向：**

- 取消赛季结束清空角色、金币和物品。
- 名册、仓库、已解锁内容、收藏与军团历史长期积累；永久死亡仍会失去对应角色。
- 可以周期更新副本、挑战主题、竞技场和榜单，但不清空养成。
- 永久养成不等于无限刷资源，也不等于属性无限增长。

**待定：**是否保留行动日、如何发放和累积、资源获取限制、晚加入玩家追赶方式。旧版“60 天重置、3 天一个游戏月、每月 12 个行动日”不再作为现行安排。

## 3. 角色与招募

### 3.1 角色构成

**当前草案：**每名角色具有身份与肖像、初始职业、基础属性、个人成长率和一个个人技能。保留早熟、均衡、晚成等差异。

| 类型 | 培养取舍 |
| --- | --- |
| 早熟 | 较快形成可用战力，适合开荒、补员与过渡 |
| 均衡 | 投入与回报相对平稳 |
| 晚成 | 初期弱，需要投入，后期形成特定优势 |

永久制下应重新评估三者的长期价值，不能让晚成角色全面替代其他类型。

### 3.2 属性

| 属性 | 作用 |
| --- | --- |
| HP | 生存能力；正式 PvE 无保护时受到致死伤害即永久死亡 |
| 力／魔 | 物理攻击／魔法攻击与治疗 |
| 技 | 命中与必杀 |
| 速 | 回避、攻速与追击 |
| 运 | 命中、回避与必杀回避；具体公式仍需统一核对 |
| 防／魔防 | 物理／魔法减伤 |
| 体格 | 抵消武器重量，不随普通升级随机成长 |
| 移动 | 每阶段移动能力，由职业决定，不随普通升级随机成长 |

### 3.3 招募与补员

**当前草案：**通过初始选择、金币招募、冒险及挑战解锁角色。

**待定：**

- 固定原创角色池如何与死亡后出现的“全新继承者”衔接：固定人物加新生代，还是职业模板生成新身份。
- 初始角色数量、免费选择人数、名册容量、招募费用与刷新频率。
- 是否保留游历招募，以及是否占用行动资源。
- 主力阵亡后的基础补员渠道、质量和恢复速度。

**底线：**即使主力阵亡，也不能让账号失去继续游玩的能力；需要低难恢复内容和可获得的补员。旧版“8 选 4、名册 14 人”只作为历史数值，不在此定案。

## 4. 职业、技能与装备

### 4.1 职业路线

**当前草案：**保留八类基础职业及二选一进阶方向，具体名称和数值仍可调整。

| 基础职业 | 主要职责 | 进阶分支 |
| --- | --- | --- |
| 剑士 | 高速近战、命中与追击 | 剑圣／刺客 |
| 斧兵 | 高物理输出 | 勇士／狂战士 |
| 重甲兵 | 前线承伤、守口 | 将军／要塞 |
| 骑兵 | 高机动、支援与突击 | 圣骑士／大骑士 |
| 天马骑士 | 飞行绕行、跨越地形 | 隼骑士／龙骑士 |
| 弓兵 | 远程压制、对飞行特效 | 狙击手／弓骑兵 |
| 魔道士 | 魔法输出 | 贤者／魔剑士 |
| 修士 | 治疗与支援 | 主教／女武神 |

职业影响武器权限、移动类型、成长率、属性上限及职业技能。保留职业短板，不让换职业变成永久收集全部优势的途径。

**已确认方向：**转职不重置总等级。转职门槛、转职印消耗、即时属性奖励及能否跨路线切换待重定；旧版“10 级早转或 20 级晚转以多赚升级次数”的取舍已失效。

### 4.2 技能

**当前草案：**一个个人技能，加当前职业技能；第一版以被动效果为主，例如追击强化、低血量增伤、援护、治疗强化。

主动技能、可装备技能槽、羁绊、盗贼、舞者等作为后续候选，不视为首版承诺。轮回和转职是否保留旧技能需单独决定。

### 4.3 武器与物品

**当前草案：**

- 武器类型：剑、枪、斧、弓、理魔法、杖。
- 武器熟练度：E → D → C → B → A → S，限制可用装备，并受职业上限约束。
- 熟练度通过实际使用提升，构成等级以外的培养线；具体经验速度待校准。
- 初期武器不设耐久；强弱之外保留重量、命中、射程、特效的取舍。
- 武器包括基础铁／钢／银系列、投掷武器、特效武器、必杀武器、勇者武器及远程武器。
- 道具包括伤药、转职印、能力药和不朽盾；当前携带栏候选为每人 5 格，多余物品进仓库。

**待定：**永久经济下的购买与掉落节奏、随身装备死亡后如何处理、能力药终身额度。

## 5. 等级、随机成长与一次轮回

### 5.1 等级与成长

**已确认方向：**角色总等级为 1–99，转职不归零，最多轮回一次。

**当前草案：**

- 每次升级，各属性按“个人成长率 + 当前职业成长率”独立随机成长，达到职业上限后不再增长。
- 成长率最低按 0；超过 100% 的部分提供额外增长概率。
- 保留随机成长带来的个体差异，不保证同一人物每次培养结果相同。
- 经验来自实际交战、击败敌人和治疗；公共奖励经验、训练作为补充培养候选。
- 不允许靠反复重来挑选升级结果。

**待定：**按 99 级重新设计成长率、职业上限、升级经验曲线、单场经验限制、培养耗时和空级保护。旧版两段各 20 级、进阶等级加 20 的计算不再沿用。

中期就应有完整配队、转职与高难挑战体验，不要求先升到 99 级才开始玩核心内容。

### 5.2 轮回

**已确认方向：**

- 存活角色一生最多一次轮回，回到 1 级，再次以 99 级为上限。
- 保留同一身份与历史，不是死亡后复活。
- 属性回到明确的一级基准，不能保留旧属性再完整叠加第二轮成长。
- 不提高职业属性上限，不刷新能力药终身额度。
- 未轮回角色也应能参与主要内容。

**当前暂定奖励：总计 30 个百分点的个人成长率分配预算。**

例如给力、速、防各加 10 个百分点；不是每项都加 30%，也不是原成长率乘 1.3。可分配至 HP、力、魔、技、速、运、防、魔防，不含移动和体格。

- 单项投入应有限制，具体上限待定；分配后固定，不通过反复改点逐项补满。
- 不跨代传递轮回奖励。
- 忽略封顶时，98 次升级的额外总属性期望为 29.4 点，不是保底收益，也不保证第二轮每项更高。

**待定：**轮回是否要求满级、所需资源或试炼、一级基准、职业与技能及熟练度保留范围。

### 5.3 防止全属性趋同

- 每个角色最多两轮自然成长，不额外加入无限突破。
- 能力药必须有限的终身额度，不能只靠商店周期限购。
- 转职奖励不能反复领取，跨职业不能无成本补齐全部短板。
- 传承不积累跨代属性、成长率或上限。
- 满级后的长期目标优先放在阵容、装备选择、职业精通候选和新挑战，而非全属性加满。

## 6. 战棋战斗

### 6.1 回合与行动

**当前草案：**一回合为我方阶段 → 敌方阶段，特殊关卡可有其他阵营。各方阶段内自行决定单位行动顺序。

每个未行动单位可执行一次“移动 + 行动”：攻击、用杖、用道具、交换物品、压制目标或待机。可以不移动；确认执行后不能撤销。交换物品是否消耗行动待最终确认。

友军可穿过、不可叠站；敌军阻挡通行。结束阶段时未行动角色待机。骑乘与飞行的再移动暂不纳入基础玩法。

### 6.2 地形与移动

四类移动方式：步行、重甲、骑乘、飞行。

| 地形 | 战术意义（当前草案） |
| --- | --- |
| 平地／街道／室内地板 | 常规通行 |
| 森林 | 增加地面移动消耗，提供回避与防御 |
| 山地 | 步行通行较慢，重甲与骑乘不可进入，飞行可越过 |
| 浅滩 | 步行与骑乘通行较慢，重甲不可进入 |
| 水域 | 当前只有飞行可进入 |
| 墙壁／建筑主体 | 所有移动类型都不可穿越 |
| 堡垒／王座 | 提供地形收益与阶段开始恢复；王座可作为压制目标 |
| 村庄 | 已有原型表现，拜访、救援与奖励玩法待定 |

飞行不享受地形回避和防御加成。地形的具体消耗、加成与恢复比例仍属数值草案。

### 6.3 交战与武器克制

**当前草案：**攻击 → 射程允许时反击 → 攻速优势方追击；勇者武器每次出手连击。每一击分别判定命中、必杀与伤害。

- 攻速受速度、武器重量和体格影响；当前追击门槛为攻速差 4，个别职业可降低门槛。
- 剑克斧、斧克枪、枪克剑；优势影响命中与伤害。
- 弓对飞行、斩马武器对骑乘、破甲武器对重甲有特效。
- 物理攻击对防御，魔法攻击对魔防；必杀提供倍率伤害。
- 初版建议采用双随机命中、单随机必杀；命中方式最终仍可调整。
- 交战前提供命中、伤害、追击及危险提示，供人和 Agent 判断风险。

具体公式、武器伤害与倍率属于后续数值校准，不把旧版数值表当作永久制平衡结论。

### 6.4 胜负、截止与撤退

目标包括：全灭敌军、击败首领、压制王座、坚守指定回合；保护、救援和撤离可作为任务扩展。

**已认可方向：**以回合截止规则兜底，接受部分动态特殊场景，不要求所有战局必能取胜。

- 每关需明确目标、失败条件与回合上限；上限多少、截止在何阶段结算待定。
- 地图不应因地形孤立让出生单位无法行动或关键目标不可达。
- 敌人堵路、战力不足、石化占位等可能造成失败，不等同于地图生成错误。
- 玩家可全军撤退，不默认每个普通角色能随时单独离场。
- 撤退不复活已死角色；经验、金币、掉落如何保留待定。
- 任务失败不自动等同于所有存活者死亡；截止、战败及特殊剧情的角色结算必须另行明确。

## 7. 永久死亡、不朽盾与传承

### 7.1 风险范围

| 场景 | 后果 |
| --- | --- |
| 正式 PvE | 无有效保护时受到致死伤害即永久死亡 |
| 快照竞技场 | 仅当局退场，不影响真实角色 |
| 练习与回放 | 不造成真实死亡或养成损失 |

死亡角色不能再参战，进入纪念名册，保留最终状态、成长历史、战绩、死亡经过及传承关系。正式冒险必须明确展示风险；Agent 出征授权与撤退策略的粒度待定。

### 7.2 不朽盾

**已认可核心效果：**携带者受到致命伤害时自动消耗，保留 1 HP，立即进入“石化庇护”，直到下一个我方阶段解除。

- 石化期间免疫伤害与死亡效果，无法移动、攻击、反击、用道具或执行其他行动。
- 留在原格占位，不自动撤离；后续连击、追击与其他敌人攻击立即受到保护效果阻止。
- 我方主动攻击被反击触发时，保护覆盖当前阶段剩余时间和之后的敌方阶段。
- 敌方阶段触发时，保护覆盖该阶段剩余时间，直到下个我方阶段。
- 解除后仍是 1 HP，恢复正常行动资格，不额外增加行动次数；可治疗、移位、继续战斗或全军撤退。
- 道具已消耗，再次致死且无保护时永久死亡。不同时增加默认濒死救援或复活流程。

**建议／待定：**

- 建议每人携带一个、占一个携带栏，未触发保留；携带限制不等于每场只能触发一次。
- 建议石化期间不可治疗、暂停援护与光环；最终交互待确认。
- 若有阶段开始持续伤害，建议在庇护下先结算，再解除，确保玩家获得操作机会。
- 战斗中补盾、交换盾、每场触发次数限制待定，避免低成本反复无敌堵路。
- 盾的来源、价格、掉率与补充速度待定；过于普遍会弱化死亡风险，过于稀缺会让玩家不敢出征。
- 保护期间战斗提前结束的结算、快照与练习中的盾规则及库存隔离待定。

### 7.3 有限传承

**已确认方向：**继承者是全新的一级角色，不是把死者完整恢复。

- 每位死者最多一份遗产，每位继承者最多接受一份，玩家可暂不选择。
- 遗产不能递归叠加；下一代只计算自身新获得的有效成果，并受同样上限约束。
- 不传递旧角色全部属性、成长率、轮回奖励或默认复制个人技能。
- 不因死亡额外发奖励，不复制装备或重复领取资源。

**遗产候选，尚未选定：**

| 候选 | 内容 | 需限定 |
| --- | --- | --- |
| 武器心得（优先评估） | 一种武器的部分熟练度 | 比例、绝对上限、职业条件 |
| 培养心得 | 一小份专属训练经验 | 额度与使用条件，不能恢复旧等级 |

建议第一版只选一种遗产。死亡时装备损失或回收单独决定，不与角色遗产混为一谈。

### 7.4 正常退役（建议，未定案）

达到条件后可永久退出参战，按与死亡相同的规则留下遗产，避免为了培养新人而故意送死。退役不可逆，门槛与收益要防止快速招募、退役刷资源。

## 8. PvE 内容与随机战场

### 8.1 内容组成

**当前草案：**

- 固定关卡：负责教学、剧情、首通目标与有设计感的战术挑战。
- 随机遭遇：提供重复冒险与不同地形、编成的变化。
- 周期高难挑战：更新任务与强敌，提供排行或收藏目标，不清空军团。
- 无损练习：研究战斗、验证阵容，不替代有风险冒险的资源收益。

随机战场可选择草地、城市、王宫内、城镇街道、山地、树林。场景差异影响通路、掩护和机动空间，不只改变外观。

尺寸尚未决定，可评估 20×20、25×25 或长方形；需要结合出战人数、接敌时间、赶路回合和整局时长选定。这里不规定生成算法或工具。

**待定：**出战人数、敌军强度增长、随机遭遇刷新和选图机制、奖励、固定关卡解锁顺序。旧版按赛季月份开放区域和按行动日增长难度不直接沿用。

### 8.2 后期挑战候选

- 救援与撤离：时间压力下规划路线并保护目标。
- 多点防守：迫使分兵，避免一个强者包办。
- 连续作战：限制恢复，考验替补与消耗管理。
- 特殊敌军：骑兵突击、远程压制、治疗配合。
- 精英 AI：集火、利用地形、保护关键角色、争夺目标。

不是第一版全部加入；先验证少量有明显战术差异的关卡。

### 8.3 评价与重试

**候选：**按通关、伤亡、回合效率设置星级、首通奖励与挑战排行。

永久死亡下，重打关卡不应倒退真实伤亡。主线能否重试、奖励是否仅一次、扫荡解锁条件均待重新决定，不直接沿用旧版“月末仅一次”和“无撤退三星”的完整规则。

## 9. 资源经济与日常活动

**当前草案：**金币用于招募、武器、伤药及其他物资；战斗提供经验、武器经验、掉落与金币；首通和挑战提供特殊奖励。

| 活动候选 | 意义 | 尚需决定 |
| --- | --- | --- |
| 正式出击 | 主体战术内容、成长与资源来源 | 行动消耗、收益、风险提示 |
| 扫荡 | 减少重复操作和 Agent 使用成本 | 解锁、收益、经验分配、是否有伤亡风险 |
| 训练 | 稳定补充熟练度或经验 | 资源消耗、培养效率 |
| 游历招募 | 扩充阵容 | 刷新机制、成本、角色来源 |
| 公共奖励经验 | 扶持新人或补齐主力 | 产出、存储与分配限制 |

不保留旧版用休整解除重伤来代替死亡的规则；是否另设存活角色的疲劳或伤病系统，尚未决定。

长期经济必须一起考虑金币和装备累积、能力药终身限制、盾的消耗、补员恢复及招募退役收益。不能仅靠周期商店限购阻止永久数值膨胀。

**待定：**行动日是否存在、日常活动节奏、商店库存刷新、追赶办法、资源产销及主力阵亡恢复成本。旧版 70% 扫荡收益、追赶阈值、初始金币等不直接沿用。

## 10. 快照竞技场（辅助 PvP）

### 10.1 基本方式

**已确认方向：**与其他玩家的防守快照对战，无需双方同时在线；真实角色不会因快照战斗死亡。

**当前草案：**进攻方亲自或由自己的 Agent 操作，防守方按预设规则 AI 行动。进攻和防守使用该期锁定状态，不受期间练级和换装备影响；竞技场不发角色战斗经验。

建议已经锁定的快照继续有效，即使对应真实角色后来在 PvE 死亡；后续新快照不再纳入死者。此项仍需确认。

### 10.2 编成与 BAN

**当前草案：**

1. 防守方选择地图，提交“出战人数 + BAN 数”的候选名单、站位、替补优先级和主将备选。
2. 每名防守单位设置进攻、伺机、固守、护卫或治疗优先行为。
3. 进攻方先看名单、属性和装备，暂不看站位与 AI 行为，再禁用指定数量的防守角色。
4. 揭晓实际防守阵容与站位，再由进攻方选人和部署；进攻方先手。
5. 防守方可预设对进攻方的禁用，按角色身份还是职业禁用待定，尤其需兼容新生代角色。

地图各自规定出战人数、BAN 数、目标与回合上限。原候选为 4–8 人、BAN 0–3 人、15–30 回合，仅供试验，不锁定。

### 10.3 赛程、匹配与奖励

**当前草案：**自愿报名、每期有限场次、开始后不重来，可投降；截止未完成按失败结算。回放可延后公开，避免泄露仍在使用的防守设置。

**待定：**期次长度、每期对手数、积分公式、匹配、名额不足与被禁用后人数不足的处理、奖励、快照更新频率和截止时限。

- 永久制下新老玩家累计投入不同，不能再宣称旧版“行动预算相同所以公平”。
- 奖励避免强者持续滚雪球，是否包含能力药等数值物品需重定。
- 固定预算或等级同步竞技可作为候选，不默认首版加入。
- 练习不提供正式收益；实时约战不是核心内容，后续再评估。

## 11. 玩家可见体验

- 经典像素战棋表现，配合适合网页的直接操作；可采用羊皮纸与战旗风格，少装饰、重信息。
- 军营集中呈现名册、培养、装备、招募、出征和周期挑战。
- 战斗中清楚区分移动范围、攻击范围、敌方威胁、已行动、石化与死亡。
- 出征前展示胜负条件、回合截止、真实死亡风险及携带保命道具。
- 交战预测、成长记录、战报与回放帮助玩家理解结果，而不是让人猜规则。
- 纪念名册与继承关系保留军团故事；具体画面布局不在本文展开。
