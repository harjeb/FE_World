## 2. 技能来源和消耗

- 个人技能1个；职业能力按该职业精通节点解锁；已学技能／被动跨职业共用5格；实际装备授予另列且卸下撤销。相同效果按来源去重，不凭中文名称合并不同技能。
- 主动武器战技纳入首版。最新确认：每个武器／兽龙职业只教授4～6项独立战技ID，通过职业精通节点学会，不随人物／职业升级免费发放。176项基础技由职业精通教授，103项强化版另走先学基础后的营地战技研修，36项武器特有战技由实物授予、卸下撤销。习得内容跨职业共用五格，基础和强化分别计数；武器熟练度只校验使用，不充当学习触发。法术书不做战技适配，原有法术学习保持。
- 《万缕千丝》职业固有能力与精通学习关联按25逐职业配置；其原作“战技装备＋1／2／3”不直接扩大本作五格上限，具体适配边界见25。原作固有指令与习得技能按来源区分，换职不把固有能力永久留存。
- 物理普通攻击／反击／被动触发不扣武器耐久；只有主动武器战技按所列成本扣。法术书普通施法与反击扣该本书独立次数，通过旅馆或食物恢复；治疗／功能杖仍按杖次数。
- 舞蹈、开锁、移位、应援等无武器指令不凭空扣武器耐久，但消耗本次单位行动，是否限定每场次数见各条；食物恢复和指令收益不能无限循环。
- 战技精通清单见[28](28-class-art-learning.md)：通用基础技有多个教师，强力基础技仅1～2职教授；强化研修必须先学基础，不绕过来源限制，也不混进本职4～6项。学会后换职保留，发动不检查教学职业名单，仍需当前武器权限、熟练度、五格、射程与资源。同一ID去重，基础与强化是不同ID、分别占格。
- 玩家能执行的每项操作 Agent 均可1:1执行；同样的可见信息、合法选项、预测、确认、费用、失败和恢复结果。包括新战技、装备、小游戏、旅馆、塔、BAN和退赛，不给人类保留专属操作入口。
