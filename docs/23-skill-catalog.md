## 2. 技能来源和消耗

- 个人技能1个；职业能力按该职业精通节点解锁；已学技能／被动跨职业共用5格；实际装备授予另列且卸下撤销。相同效果按来源去重，不凭中文名称合并不同技能。
- 主动武器战技也属于技能内容，不能继续引用旧“主动战技暂不纳入核心”把它延期。习得战技占五格中的一格；武器专属授予战技随实物生效、不永久学会，此为首稿适配。
- 物理普通攻击／反击／被动触发不扣武器耐久；只有主动武器战技按所列成本扣。法术书普通施法与反击扣该本书独立次数，通过旅馆或食物恢复；治疗／功能杖仍按杖次数。
- 舞蹈、开锁、移位、应援等无武器指令不凭空扣武器耐久，但消耗本次单位行动，是否限定每场次数见各条；食物恢复和指令收益不能无限循环。
- 玩家能执行的每项操作 Agent 均可1:1执行；同样的可见信息、合法选项、预测、确认、费用、失败和恢复结果。包括新战技、装备、小游戏、旅馆、塔、BAN和退赛，不给人类保留专属操作入口。

## 7. 生效顺序与保护边界

1. 校验角色／地图／职业／射程／目标／活动占用、物品实例和资源；返回真实成本与战斗预测。
2. 确认后支付一次战技耐久或法术／杖次数；同一命令幂等，失败验证不扣资源。
3. 判埋伏等顺序，再逐击判命中、单个攻击触发、必杀、地形／属性、防御技能、伤害。
4. 致命保留先判，失败才扣不朽盾；普通角色真实死亡，神主角按既定规则撤退。盾后石化的后续连击立即停止。
5. 吸血、再生、杖、药、地形、光环等回血统一经过禁疗检查，不能把石化单位抬回满血；死亡不复活。
6. 战后封印、物品消耗、经验、精通与事件同事务保存；跨图／断线按剩余期限恢复，换界面不重判。

## 8. 首版内容与验收

- 保留现行12技能的准确说明；新增每项明确ID、来源、职业节点、概率／条件、成本、叠加、目标和持续阶段。
- 单独验收舞者／神乐再行动、战车直线、白魔法攻击、成长装备、魅力对应机制；不能只填目录后解除职业禁用。
- 对概率0／100、HP1、免疫首领、盾石化、多段中断、资源不足、未命中、同名多来源、移位非法目标和重连分别验证。
- 保护期不治疗，法术普通施放耗本书次数，物理普通攻击不耗耐久；精工＋10不影响法术次数。
- 每个玩家可点的技能、预测、目标选择、确认／取消和使用操作均有同规则 Agent 路径；小游戏停止判定与可见信息也一致。
- 参考效果不等于本作已实现，不以参照平台的婚配、原作复活、倒带或无限资源规则覆盖本作永久军团约束。
