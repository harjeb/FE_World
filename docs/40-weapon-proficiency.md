# 40 · 武器熟练度的火纹参考与本作实现

目录版本54、战斗规则`rules-v25`采用下列规则。数值针对本作一年500天、可持续后台培养的日历调整。

## 原作资料

- [《圣魔之光石》计算规则](https://serenesforest.net/the-sacred-stones/miscellaneous/calculations/)：E／D／C／B／A／S累计经验1／31／71／121／181／251，各档新增需求30／40／50／60／70；每次出手累计，击杀一击双倍，未命中或零伤害仍可积累。S级对应武器命中、必杀各+5。
- [《觉醒》计算规则](https://serenesforest.net/awakening/miscellaneous/calculations/)：每次交战或用杖给2点，追击不额外增加；C／B／A给予按武器区分的攻击、命中或治疗加成。
- [《风花雪月》技能等级](https://serenesforest.net/three-houses/characters/skill-levels/)：扩展E至S+，战斗外可以教学训练；累计C300、B680、A1320、S2520、S+3600，后期需求明显上升。
- [Fire Emblem Wiki · Weapon experience](https://fireemblemwiki.org/wiki/Weapon_experience)：各代门槛与按出手／按交战统计的对照。

本作采用每次实际出手1点，结合《觉醒》的分类加成、《圣魔》的S级命中／必杀，以及《风花雪月》后期明显拉长的培养节奏。拳、兽、龙、SS／SSS为本作扩展；不额外给予击杀双倍经验。

## 成长曲线

`backend/common/data/weapon-proficiency.ts`为前后端共同数据源，`game/model.ts`兼容导出`RANK_EXP`。

| 等级 | 累计经验 | 从上一档新增需求 |
|---|---:|---:|
| E | 0 | — |
| D | 50 | 50 |
| C | 200 | 150 |
| B | 600 | 400 |
| A | 1500 | 900 |
| S | 3000 | 1500 |
| SS | 5000 | 2000 |
| SSS | 8000 | 3000 |

保留已确认的E→D50点。原目录53的S仅350点，低于一年的500天，不适合每天1点的持续培养；现调整为3000点。

第三章最早第1482天开放。即使同一角色每10天打一场、每场实际出手8次（148场、1184点），每场占2天、余下1186天全用于该武器培养，合计2370点仍为A级。单纯连续培养1482天也未到S。这是培养预算检查，不另设章节硬锁；极端反复刷战仍可更快达到门槛，推迟主线同样不会锁住培养。

## 获得经验

- 野外、任务、副本与年度大竞技场，角色每次实际出手获得对应武器1点；追击、勇者连击、固定多段与反击逐击累计。未命中、零伤害仍计1点；没有实际反击不计。普通竞技场和练习维持不增加永久熟练度。
- 多目标战技按实际发生的各次出手累计；不额外按战技行动或目标数量再发一次。
- 攻击法术同样逐击累计，施放事件不重复加点。白魔法对应杖，黑／暗魔法对应理。
- 治疗、全体治疗、复原、传送、救援与状态杖每实际使用一次1点。状态未命中仍计，群疗不按治疗人数翻倍。非攻击法术每次施放1点，不按效果事件重复计入。
- 失败／撤离保留存活者实际获得的经验，普通阵亡者沿用原结算逻辑。
- 营地训练保持每人200金币、全组共享3日、所选组内每种武器各3点；后台派遣保持每种所选武器每日1点。单位的战斗／训练／派遣占用校验不变。
- 训练允许提前学习当前职业不能使用的武器，装备／施法权限仍由职业检查。转职保留熟练度，职业精通单独积累。

## C～S加成

只有当前实际使用的武器类别生效，不叠加携带的其他武器等级。下表各档是该档总加成，不是与前档相加。

| 武器 | C | B | A | S |
|---|---|---|---|---|
| 剑 | 攻击+1 | 攻击+2 | 攻击+3 | 攻击+3、命中+5、必杀+5 |
| 枪／弓／理／兽爪／龙石 | 攻击+1 | 攻击+1、命中+5 | 攻击+2、命中+5 | 攻击+2、命中+10、必杀+5 |
| 斧／拳 | 命中+5 | 命中+10 | 攻击+1、命中+10 | 攻击+1、命中+15、必杀+5 |
| 杖 | 治疗+1 | 治疗+2 | 治疗+3 | 治疗+5 |

E／D无额外加成，SS／SSS沿用S档，不再额外叠数值。高等级仍可用于更高装备／法术／战技与职业门槛。

战斗预测、实际伤害和单位面板使用同一份数据，普通攻击、反击、魔法武器、龙石与主动战技均适用。攻击加成在武器特效倍率之后加一次，不被特效三倍放大；必杀正常按最终伤害计算。战技固定命中、禁止必杀等覆盖规则保留。武器三角处于劣势时仍保留等级加成。

杖加成适用于治疗杖与按杖熟练度施放的白魔法治疗，群疗各目标分别增加相同治疗量；不超过最大HP，完全回复杖仍只补满，石化／禁疗仍无效。杖加成不增加状态杖命中、传送距离、白魔法攻击或再生等其他效果。

名册显示当前等级的具体加成及真实经验进度，不添加常驻教学段落。

## 野图敌军

目录65起，新普通随机野图敌军熟练度沿用招募的等级曲线，每12级升一档；主将同等级提前一档，替代目录64直接取职业上限的做法。按最终等级计算，包含困难等级加成。

| 等级 | 小怪 | 主将 |
|---|---|---|
| 1–12 | E | D |
| 13–24 | D | C |
| 25–36 | C | B |
| 37–48 | B | A |
| 49–60 | A | S |
| 61–72 | S | SS |
| 73–84 | SS | SSS |
| 85以上 | SSS | SSS |

各职业允许的武器类别分别计算，受职业上限约束（初／中／上级S、最上级SS、神将级SSS），并保证满足实际携带装备的最低熟练度；模板预置的S不再作为下限。困难追加敌军用小怪曲线、不继承主将加档。当前普通野图基础等级仍封顶50，本次不扩大等级或职业阶段。仅当前实际使用类别贡献现有加成，不新增首领专属倍率，也不提升携带装备。任务／副本／经典／固定首领及已保存战场不变。

## 旧档与冻结战斗

单位标记升级为`weaponExpVersion: 3`。缺失标记的原始曲线与标记2的目录53曲线分别按其原门槛换算一次：保留现有等级，将超过旧等级起点的已赚取点数加到新起点。

- 原始曲线C级83点：C级70+本档13，迁移到新C级213。
- 目录53曲线C级123点：C级110+本档13，同样迁移到213。
- 已有S级355点（目录53）：保留S级，迁移到3005点。
- 旧D级只存30点的角色至少保留D级50点；保存、再次读取不会重复换算。

目录53进行中战斗保留旧的每交战／施放／用杖2点奖励；目录53之前保留每图每类2点奖励。新战斗按逐击1点计算。战斗公式变化使规则版本升至`rules-v25`；旧规则回放只显示冻结的终局快照，不按新公式重新模拟。升级前宜完成旧规则下的进行中战斗，既有角色属性与学会的等级保留。
