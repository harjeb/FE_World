# 25《万缕千丝》技能、战技与职业对应

更新：2026-10-17。关联：[15 职业目录](15-class-catalog.md)、[23 首版技能配置](23-skill-catalog.md)、[22 装备资源](22-equipment-catalog.md)、[TODO](../TODO.md)；文档补漏任务`fe-world-8jl`，实现任务`fe-world-bwo`。

《万缕千丝》是本作职业体系的主参考，技能目录应同时覆盖它的职业固有能力和精通奖励。本文补齐现用58项参考职业的关联与效果；GBA／NDS／3DS／NS前作作为23的补充。**这里记录参考资料及适配要求，不表示运行时已实现**；当前仍只有23第3节的12项技能，职业精通节点仍需替换。

本文10项战技／指令仅是职业固有／精通引用的子集。**完整首版主动武器战技为[26](26-weapon-art-catalog.md)的283项主参考＋17项补充＋[29](29-original-weapon-arts.md)的15项原创，共315项**；此前23的24项是示例，不是内容上限，也不宣称全部345条资料都要实装。

2026-10-18最新修正：战技通过独立职业精通学习，每个武器／兽龙职业只教授4～6项独立ID；基础和强化分别计数，103项强化版另走独立研修。下文“精通奖励”保留原作关联作为参考，本作具体清单以28为准；不改变其他被动／职业能力的精通机制。武器熟练度只约束使用，不代替精通。

本作教学名单见[28](28-class-art-learning.md)：原表某战技关联一个职业，不表示所有通用战技在本作都只有一个来源；部分强力战技按最新确认限定1～2个教师，例如流星由刀剑将领／刃辉神将教授、落影之刃仅探影者教授。学会后换职保留，发动不要求当前职业在教师名单内。

## 6. 与本作规则对接

- **五格与固有来源。**原作战技装备＋1／2／3是来源事实；本作已学被动和已学战技仍共用五格。首版将这三项记为职业参考元数据，不给第6–8格；真正授予的职业固有指令另列，卸职撤销，不永久学会或伪装成免费习得技能。
- **次数倍率与每本书。**黑／白魔法倍率作用于对应书的可用容量，原始剩余与已耗次数按物品实例保存；切职、转交、换书不补次数。容量增加只增加上限，新增部分需旅馆／食物填充；降低上限不使当前次数超过新上限。再次提高上限不能找回被裁剪次数；同类倍率取最高。食物按恢复时容量计算，活动开始冻结来源，活动中禁止换职刷容量。
- **耐久与即席修理。**主动战技先验足额耐久并支付；10%免耗结果只结算一次，可同事务返还本次实扣成本，未命中也按相同规则。重试不重掷、不重复返还、不修到比使用前更高；0耐久不能赌免费战技。普攻／物理反击／被动原本扣0，不能借此返还虚构耐久。
- **回血与再行动。**残心、治疗加成等统一过石化禁疗；强打后辅助不能复活或治疗石化单位。舞蹈、特别舞蹈、神乐、咒歌、军师射程都走同一目标／阶段规则，不能组合无限刷新行动或刷空辅助精通。
- **属性与成长。**神将＋10是装备中的习得技能效果，卸下失效；现行HP150封顶，其余八项无数值上限，等级99与成长率百分比规则保持；成长传承仍按00，只冻结合法成长来源，不把临时属性或未知成长曲线塞入遗产。战车等级成长若核实后加入，升级前冻结等级／职业来源，禁止换职或回放重复结算。
- **同名冲突。**主动流星与被动流星、固定20%大盾与技巧%近战盾、暗月与月光、原作神舞与本作神乐均用不同ID。技能和战技表同时出现的跳舞／咒歌是一项授权及其执行效果，不算两次加成。
- **玩家／Agent。**职业能力、战技选择、目标、概率／成本预览、乘降、追加辅助、确认／取消与恢复结果全部1:1。尚未实现的指令不能只给网页加按钮，预测、事务、回放和Agent路径共同验收。
