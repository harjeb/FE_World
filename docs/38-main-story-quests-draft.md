# 38 主线任务设计稿（草案）

更新：2026-10-20。关联：[00 玩法](00-game-design.md) §9.4.2、[13](13-backend-target-design.md) §6.3、[20 地区任务](20-region-quests-reputation.md)、[24 经典地图接入](24-classic-scenarios-integration-todo.md)、[37 隐藏要素与跨时空招募](37-hidden-content-cross-time-recruit.md)。

本文只记录用户已确认的方向；“待定”项确认前不实现。现有八章（`backend/common/game/story.ts`）只有标题、认识、事件文字和线索，对白与任务“仍待制作”。

## 1. 已确认

- **不新建任务系统**，把现有任务（`Quest`）扩成可挂主线：每章配主线任务，复用地区任务、连战副本、隐藏要素与奖励键机制。
- **线索补充背景**：探索发现、隐藏要素（古旧地图、密室、时空碎片等）可作为线索来源，不另设一套收集系统。
- **庆典与主线**：大竞技场视为大陆上一年一度的庆典，窗口仍是每年末 18 日，**不改日历**。主线章节“时间到就算”：窗口到了章节就推进，不要求报名或打过海选，名次也不阻挡。
- **庆典期间的商店活动**：庆典窗口内，**王都每月商店**整家店打折；每件商品各自在 50%～65% 里随机一个折扣（折扣，即实付为原价的 35%～50%）。库存数量和每月限购不变。
- **主线战斗复用经典图改编**，并做修改：城镇（村庄）位置、宝箱位置等。沿用 [24](24-classic-scenarios-integration-todo.md) 的适配层，只改适配数据，不动原作素材。
- **地区招募的固定剧情角色**：各地区解锁的招募角色视为带固定剧情的人物，招募后可解锁特别任务或新道具。招募与永久死亡基本不影响主线推进。
- **最终首领不在第八章**：第八章之后，在高难地区解锁隐藏首领。

## 2. 与现有规则的关系（需要核对）

| 现有规则 | 本次方向 | 说明 |
| --- | --- | --- |
| 名次、海选、地区通关都不阻挡章节（`story.ts` 头注释；窗口为每年末 18 日） | 时间到就算，窗口仍 18 日 | 与现有实现一致，章节开放逻辑不变；主线任务只需挂在“章节已开放”上。 |
| 跨过赛事日期时赛事保留为待处理，不丢资格 | 不变 | 赛事参与仍是可选的玩法，不影响主线推进。 |
| 地区固定招募人物（雷恩、伊格、米拉）由 `recruit` 字段发放 | 招募后解锁特别任务／新道具 | 复用 `requires`：加“已拥有某人物”条件，类似已有的“持有某物品”。 |
| 王都每月商店（`SHOP_STOCK`）库存每季补货，价格按目录价 | 庆典窗口内整店打折，每件 50%～65% | 需要新增价格折扣层，只作用于每月商店的买入价；地区声望商店、铁匠铺生产成本、出售价不变（默认，未另行确认）。 |

## 3. 实现思路（均未开工）

1. **章节挂任务**：每章 1～N 个主线任务，`requires` 加“章节已开放”；任务奖励使用独立唯一键，不与赛事奖励混用。
2. **人物触发任务**：任务条件加“拥有某人物”（含已加入名册、不论存活）；人物阵亡不撤销已解锁的剧情。
3. **经典图改编**：每个主线战斗在适配文件里写独立的物件和事件（村庄、宝箱位置），由生成脚本保留；与隐藏要素共用 `secret.quest` 的“仅在指定任务里出现”机制。
4. **隐藏终局首领**：高难地区的解锁条件和首领图另行设计，不计入八章。

## 4. 待定

- 庆典打折：随机种子按账号还是全服，是否每个庆典日重抽（默认按账号、整个庆典固定一份）；不朽盾、能力药、转职印等每月限量的稀有品是否也参与打折（整店打折下默认参与，会降到原价的 35%～50%）；折后价显示方式。
- 每章主线战斗用哪张经典图，几张图、敌军等级、奖励；是否沿用现有公共经验 1350。
- 哪些地区人物解锁哪些特别任务／道具；线索具体放在哪些任务或宝箱里。
- 隐藏终局首领所在高难地区、解锁条件、首领图与奖励。
- 对白与过场的呈现方式（任务简报文字、战斗内提示、还是独立对话界面）。
