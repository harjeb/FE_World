# 38 主线任务、伙伴任务与庆典折扣

更新：2026-10-20。关联：[00 玩法](00-game-design.md) §9.4.2、[13](13-backend-target-design.md) §6.3、[20 地区任务](20-region-quests-reputation.md)、[22 装备来源](22-equipment-catalog.md)、[24 经典地图接入](24-classic-scenarios-integration-todo.md)、[37 隐藏要素与跨时空招募](37-hidden-content-cross-time-recruit.md)。

实现状态：目录 v56 已包含王城阴谋八章、背景与56段任务对白、第八章邪神化教首战和通关后禁忌之地。最新人物与揭露节奏见 [42 王城主线](42-royal-capital-story.md)。本文保留任务、奖励与地图配置；数值仍可按试玩校准。

## 1. 已确认

- **不新建任务系统**：主线任务和伙伴任务都是现有任务（`Quest`）的扩展，复用出征、结算、奖励唯一键。
- **线索补充背景**：线索来自探索发现，不另设收集系统。
- **庆典与主线**：庆典窗口仍是每年末18日，不改日历。章节在日期到达且此前调查完成后揭露，不要求夺冠。第八章收尾战等待本届参赛结束，未参赛者等到第4000日；旧档已完成章节保留。
- **庆典期间的商店活动**：庆典窗口内，**王都每月商店**整家店打折；每件商品各自在 50%～65% 里随机一个折扣（折扣，即实付为原价的 35%～50%）。库存数量和每月限购不变。
- **一章是一条任务链**：每章两个前置任务 + 收尾战，前置任务的类型各章不同（派遣、提交材料、副本宝箱找任务物品、单挑、普通竞技场胜场、酒馆小游戏胜次）。
- **主线战斗复用经典图改编**：改动城镇（村庄）位置、宝箱位置等，沿用 [24](24-classic-scenarios-integration-todo.md) 的适配层。
- **地区招募的固定剧情角色**：招募后可解锁特别任务或新道具；招募与永久死亡基本不影响主线推进。
- **第八章与通关后**：第八章竞技场结束后击败邪神化的教首；通关后开放禁忌之地，依次挑战缚门者、逆祷者和魔神。

### 3.1.1 前置任务

每章两个前置任务，**类型各章不同**，全部完成后才能接收尾战；两个前置任务不分先后。六种类型：

| 类型 | 完成条件 |
| --- | --- |
| 派遣 | 章节开放之后出发的一次派遣满 N 日、地区不限，返程那一刻自动完成；一次派遣只计入最早一个还没完成的章节 |

| 副本宝箱找物品 | 在指定固定经典远征的某张图里找到一只旧箱子，取得任务物品（不可出售、不扣除）；箱子只在**对应章节开放之后**、**该远征里**出现，整趟完整通关后入库，每个账号一次；仓库里持有即完成 |
| 单挑 | `START_STORY_DUEL`：选一名己方角色，对手是**随机生成的人物**（名字随机，写成“名字（刮名人）”这样的形式）：等级 = 现役名册里的**最高等级** +1（第 3、5 章）／+2（第 8 章），职业是与应战角色**同阶级**（同一 stage：初级／中级／上级／最上级／神将级）的**随机**一个，只从目录里可用、有攻击手段的人类职业里按种子挑（纯治疗、兽龙种族职业不参与），免得对手不会还手；借小型经典图，推进 1 日，**真实死亡**；获胜完成，失败可再次挑战（再打会换一个随机人物）；不算地区讨伐 |
| 普通竞技场胜场 | 章节开放之后在普通竞技场赢 N 场（只计进攻胜利，不计投降） |
| 酒馆小游戏胜次 | 章节开放之后在酒馆小游戏里赢 N 次（返还高于下注） |

### 3.5 高级物品的上架与成长药的获取

**王都商店按年份上架高级物品**（用户反馈开局就能买到太多高级物品）：

| 时间 | 上架的物品 |
| --- | --- |
| 开局（第 1 年） | 基础武器、伤药、解毒药、以太口粮、材料、转职印（培养必需） |
| 第 2 年（第 500 日起） | 特效药、完整料理、六种能力药（天使之衣、秘传之书、速度之羽、女神像、龙盾、护身符） |
| 第 3 年（第 1000 日起） | 不朽盾 |

未到日期的物品不出现在 `GET_SHOP.items` 里，列在 `locked`（物品、名字、上架日）；`BUY` 会拒绝并说明哪一年上架。旧档的库存行仍用 `ensureShopRows` 补插，只是按日期显示。

**属性成长药（能力药）的获取**（以前只有商店、几个固定宝箱和一个生产配方）：

- 每个地区的第二个核心任务（`-8`）给一枚，六种药按地区轮换，十二地一共十二枚；
- 主线前置任务：六种各一枚，分在第 3、4、5、6、8 章较难的任务里（单挑与找物品）；
- 三个伙伴任务各一枚（秘传之书、龙盾、护身符）；
- 经典图里约四分之一的普通宝箱改放一枚成长药（生成脚本按哈希固定，隐藏要素、主线改编和找物品的箱子不参与）。

每名角色每项最多吃 5 次、合计 20 次，来源仍然有限。

**数值依据**（按现有系统的概率和频率估算，待人工试玩校准）：
- 普通竞技场每季 1 个竞技日、每个竞技日 3 场进攻，一年约 12 场；胜场要求 2／3／3，按五成胜率大约需要一到两个竞技日，不会拖住一章。
- 酒馆小游戏每季最多 6 局；猜大小胜率约 49%（出豹子通吃），青蛙最高 40%。2 次胜利一个季度约 88%，3 次约五成、两个季度基本稳妥，所以酒馆任务要求 2／3。
- 派遣 3～6 日远小于一年 500 日，只占队伍的时间。
- 提交材料：矿石 ×8、药草 ×15，按王都商店价约 1000～1200 金币，是该章金币报酬的两到三成；材料也能自己种、派遣带回。
- 单挑：对手等级为名册最高等级 +1／+1／+2，同阶级随机职业，真实死亡。应战者比对手低 3 级以上时，页面要求先勾选确认风险；接口本身不拦。

说明：副本找物品最多只有 4 处，因为只有六条固定经典副本里有宝箱，随机副本是生成地图没有宝箱；箱子位置在该图离出击点最远的四分之一可达区域，位置固定。酒馆在第 2 年（第 500 日）开放，第 1 章的酒馆任务要等到那时才能计数。旧档里已被旧按钮记为完成、收尾战还没打的章节，不受前置任务限制。线索仍只有收尾战地图里的一只，前置任务不另给线索。

### 3.3 庆典折扣

- 范围：只有王都每月商店（`SHOP_STOCK`）的买入价；地区声望商店、铁匠铺生产成本、出售价不变。
- 整店打折，**每月限量的稀有品（不朽盾、能力药、转职印）也参与**，会降到原价的 35%～50%。如不想这样，需要排除这几类。
- 前端：商店行显示原价划线和“庆典 −N%”标签。

## 4. 待定

- 已实现的王城终战和禁忌之地关卡仍需持续试玩校准，地图、首领与触发配置见 [42](42-royal-capital-story.md)。
- 主线报酬、公共经验、伙伴任务报酬、前置任务的天数、材料数、胜场数和单挑对手等级的校准；主线任务的难度是否需要按队伍规模调整。
- 非战斗任务是否也给线索（现在每章只有收尾战一条）；材料是否限定来源（现在不限）。
- 后续如需战斗地图内的演出、专用立绘或分支对白，可在现有56段任务场景基础上继续扩展。
- 伙伴任务是否需要专属新道具；更多固定人物加入后的扩展方式。
- 稀有品是否排除出庆典折扣。

### 3.6 地区声望商店与起步金币

用户反馈声望商店塞满低级商品、起步金币太多可以开局大采购，已改：

- **声望商店只留高级商品**：池子里只有 C 级及以上的武器／法术书、六种能力药、特效药和成长传承石（药草、料理、E／D 级基础装备都不在这里）。每个地区每季只上架 4 件（账号＋季度做种子，季内固定、不随声望变化，长期每件都会轮到，所以所有高级装备仍有取得途径），**每件本季限购 1 件**（特效药 2 件），换季清零。
- **基础装备改由王都“军需处”供应**：E／D 级基础装备 46 件组成轮换池，每季上架 8 件、每件限量 3，同样按账号和季度做种子，长期每件都买得到。
- **起步金币 13,120 → 1,500**：只够买几瓶伤药或一件钢制武器。测试夹具继续用旧金额（`SEED_GOLD`）。
- 密室宝箱的“能买到的最高装备级”现在把军需处的 D 级也算进去，所以最早期是 D 级而不是 E 级。

### 3.7 目标类支线任务（悬赏）与任务板

用户要求增加“直接能完成的”任务（例如第 3 章一进入就有“击杀 10 名剑职业敌人”，打完就能交，不用特地接取），并让任务界面一般有 4～7 个能做的任务、标明主线／支线。

**目标类支线任务**（`bounty-*`，`region 0`，11 项）：不用接取；满足章节门槛后自动计数，打完在任务板（或任意任务页）直接交任务。计数规则：

- 只算普通出战（`mode=field`：地区野外、任务、副本图、挑战塔、单挑）；竞技场和年度赛事的对手是别人的快照，不计。
- 击杀类按场上被击败的敌军结算，可限定职业路线（`CLASSES[职业].route`：剑术、弓术、重甲、魔法、飞行……）；胜利类每赢一场 +1；副本类每完整通关一次 +1（含重复与困难）。
- 章节门槛：有 `requires.chapter` 的悬赏在该章开放之后才开始计数，之前打的不算。完成后记入 `questsDone`，用 `CLAIM_QUEST_REWARD` 交付（不记声望）；`START_QUEST` 会拒绝。

**任务板**（`GET_QUESTS.board`，任务页顶部）：把现在能做、能交的任务放在一起，**最多 7 条、尽量不少于 4 条**，每条标明“主线”或“支线”。优先级：可交付的 > 主线（当前章的前置任务和收尾战，最多 3 条；章节还没开放时只给“第 N 章将在第 X 日开放”的预告，不剧透标题）> 进行中的目标类支线（新章节的排在前面）> 可接取的伙伴任务和地区任务。目标类支线带进度条；可交付的有“交任务”按钮，其余是“前往”链接。
