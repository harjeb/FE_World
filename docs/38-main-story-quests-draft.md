# 38 主线任务、伙伴任务与庆典折扣

更新：2026-10-20。关联：[00 玩法](00-game-design.md) §9.4.2、[13](13-backend-target-design.md) §6.3、[20 地区任务](20-region-quests-reputation.md)、[22 装备来源](22-equipment-catalog.md)、[24 经典地图接入](24-classic-scenarios-integration-todo.md)、[37 隐藏要素与跨时空招募](37-hidden-content-cross-time-recruit.md)。

实现状态：除“隐藏终局首领”外全部已实现（目录 v35）。用户确认的规则在 §1；§3 的数值、地图、报酬是实现时取的默认值，数值待校准，可按需要调整。

## 1. 已确认

- **不新建任务系统**：主线任务和伙伴任务都是现有任务（`Quest`）的扩展，复用出征、结算、奖励唯一键。
- **线索补充背景**：线索来自探索发现，不另设收集系统。
- **庆典与主线**：大竞技场视为大陆上一年一度的庆典，窗口仍是每年末 18 日，**不改日历**。主线章节“时间到就算”：窗口到了章节就开放，不要求报名或打过海选，名次也不阻挡。
- **庆典期间的商店活动**：庆典窗口内，**王都每月商店**整家店打折；每件商品各自在 50%～65% 里随机一个折扣（折扣，即实付为原价的 35%～50%）。库存数量和每月限购不变。
- **主线战斗复用经典图改编**：改动城镇（村庄）位置、宝箱位置等，沿用 [24](24-classic-scenarios-integration-todo.md) 的适配层。
- **地区招募的固定剧情角色**：招募后可解锁特别任务或新道具；招募与永久死亡基本不影响主线推进。
- **最终首领不在第八章**：第八章之后，在高难地区解锁隐藏首领（**未做，由用户另行设计**）。

## 2. 实现概览

| 项 | 做法 | 位置 |
| --- | --- | --- |
| 主线任务 | 8 个，`story-1`～`story-8`，`region 0`（不属于任何地区），单图经典地图任务，2 日，每章一次；章节开放后可接 | `common/game/story-quests.ts` |
| 章节完成 | 打赢主线任务即自动完成该章（`storyCompleted`）；`COMPLETE_STORY_EVENT` 只补记，且必须先完成任务。公共经验 1350 仍用 `CLAIM_REWARD` 单独领取 | `api/handlers.ts` `finishBattle` |
| 旧档 | 旧版已点过“完成本章事件”的章节仍算完成；其主线任务仍可补打，领取线索和报酬 | `GET_STORY.quest.legacyCompleted` |
| 地图改编 | 适配文件里用 `hideIn` 在主线任务中隐去原村庄／宝箱，用 `secret.quest` 加入挪位后的新物件和线索箱；其他场合（普通任务、副本、塔层）保持原样 | `adaptations.json`、`build_adaptations.py` `apply_story` |
| 线索 | 每章一只“被遗落的箱子”（放在离出击点最远的四分之一区域），内有任务物品 `story_clue_N`（不可出售、不可带进战斗）；每个账号只能取得一次，胜利后才入账 | `common/game/items.ts` |
| 伙伴任务 | `companion-ren`／`companion-ig`／`companion-mira`，并入对应地区的任务列表；对应人物经地区远征（`gw6`／`ih6`／`wl6`）领取过后才出现，之后阵亡不撤销 | `requires.character` |
| 庆典折扣 | `GET_SHOP`／`BUY` 在大竞技场窗口内按 `festivalDiscount` 计价；种子为账号＋届次＋商品，整个庆典固定一份 | `common/game/festival.ts` |

主线任务不加地区探索度和声望，也不触发“地区首讨”奖励；报酬为金币和物品，用 `CLAIM_QUEST_REWARD` 领取。

- 选图原则：避开两条固定隐藏路线（`clx-fe6`／`clx-fe7`）、六条固定经典副本和时空试炼用的图，八章各用一张不同的图。
- 敌军等级：按日期取该年末的基础等级（约 20／35／47／57／66／74／81／87）再加该图的适配难度。
- 报酬：每章金币 `2000 + 500×章号`，另 2 份伤药。数值待校准。
- 村庄、宝箱：数量不变、掉落不变，位置由固定哈希在“出击点可达”的格子里重新挑选（村庄离出击点 5～22 步，宝箱 8 步以上，彼此至少隔 4 格），重新生成结果不变。

### 3.3 庆典折扣

- 范围：只有王都每月商店（`SHOP_STOCK`）的买入价；地区声望商店、铁匠铺生产成本、出售价不变。
- 整店打折，**每月限量的稀有品（不朽盾、能力药、转职印）也参与**，会降到原价的 35%～50%。如不想这样，需要排除这几类。
- 前端：商店行显示原价划线和“庆典 −N%”标签。

## 4. 待定

- **隐藏终局首领**：所在高难地区、解锁条件、首领图与奖励（用户另行设计）。现有 `GET_STORY.finalBoss` 仍指向挑战塔终层，待替换。
- 主线报酬、公共经验、伙伴任务报酬的数值校准；主线任务的难度是否需要按队伍规模调整。
- 对白与过场的呈现方式：目前只有任务简报、线索说明和后记文字，没有战斗内对话。
- 伙伴任务是否需要专属新道具；更多固定人物加入后的扩展方式。
- 稀有品是否排除出庆典折扣。
