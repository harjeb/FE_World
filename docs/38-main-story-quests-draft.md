# 38 主线任务、伙伴任务与庆典折扣

更新：2026-10-20。关联：[00 玩法](00-game-design.md) §9.4.2、[13](13-backend-target-design.md) §6.3、[20 地区任务](20-region-quests-reputation.md)、[22 装备来源](22-equipment-catalog.md)、[24 经典地图接入](24-classic-scenarios-integration-todo.md)、[37 隐藏要素与跨时空招募](37-hidden-content-cross-time-recruit.md)。

实现状态：除“隐藏终局首领”外全部已实现（目录 v42）。用户确认的规则在 §1；§3 的数值、地图、报酬是实现时取的默认值，数值待校准，可按需要调整。

## 1. 已确认

- **不新建任务系统**：主线任务和伙伴任务都是现有任务（`Quest`）的扩展，复用出征、结算、奖励唯一键。
- **线索补充背景**：线索来自探索发现，不另设收集系统。
- **庆典与主线**：大竞技场视为大陆上一年一度的庆典，窗口仍是每年末 18 日，**不改日历**。主线章节“时间到就算”：窗口到了章节就开放，不要求报名或打过海选，名次也不阻挡。
- **庆典期间的商店活动**：庆典窗口内，**王都每月商店**整家店打折；每件商品各自在 50%～65% 里随机一个折扣（折扣，即实付为原价的 35%～50%）。库存数量和每月限购不变。
- **一章是一条任务链**：每章两个前置任务 + 收尾战，前置任务的类型各章不同（派遣、提交材料、副本宝箱找任务物品、单挑、普通竞技场胜场、酒馆小游戏胜次）。
- **主线战斗复用经典图改编**：改动城镇（村庄）位置、宝箱位置等，沿用 [24](24-classic-scenarios-integration-todo.md) 的适配层。
- **地区招募的固定剧情角色**：招募后可解锁特别任务或新道具；招募与永久死亡基本不影响主线推进。
- **最终首领不在第八章**：第八章之后，在高难地区解锁隐藏首领（**未做，由用户另行设计**）。

## 2. 实现概览

| 项 | 做法 | 位置 |
| --- | --- | --- |
| 主线收尾战 | 8 个，`story-1`～`story-8`，`region 0`（不属于任何地区），单图经典地图任务，2 日，每章一次；章节开放且两个前置任务完成后可接 | `common/game/story-quests.ts` |
| 前置任务 | `story-N-a`／`story-N-b`，六种类型；完成记入 `flags.storyStepsDone`（永久），胜场进度记 `flags.storyProgress`；`START_QUEST` 在前置未完成时拒绝收尾战 | `api/story.ts`、`COMPLETE_STORY_STEP`、`START_STORY_DUEL` |
| 章节完成 | 打赢主线任务即自动完成该章（`storyCompleted`）；`COMPLETE_STORY_EVENT` 只补记，且必须先完成任务。公共经验 1350 仍用 `CLAIM_REWARD` 单独领取 | `api/handlers.ts` `finishBattle` |
| 旧档 | 旧版已点过“完成本章事件”的章节仍算完成；其主线任务仍可补打，领取线索和报酬 | `GET_STORY.quest.legacyCompleted` |
| 地图改编 | 适配文件里用 `hideIn` 在主线任务中隐去原村庄／宝箱，用 `secret.quest` 加入挪位后的新物件和线索箱；其他场合（普通任务、副本、塔层）保持原样 | `adaptations.json`、`build_adaptations.py` `apply_story` |
| 线索 | 每章一只“被遗落的箱子”（放在离出击点最远的四分之一区域），内有任务物品 `story_clue_N`（不可出售、不可带进战斗）；每个账号只能取得一次，胜利后才入账 | `common/game/items.ts` |
| 伙伴任务 | `companion-ren`／`companion-ig`／`companion-mira`，并入对应地区的任务列表；对应人物经地区远征（`gw6`／`ih6`／`wl6`）领取过后才出现，之后阵亡不撤销 | `requires.character` |
| 庆典折扣 | `GET_SHOP`／`BUY` 在大竞技场窗口内按 `festivalDiscount` 计价；种子为账号＋届次＋商品，整个庆典固定一份 | `common/game/festival.ts` |

主线任务不加地区探索度和声望，也不触发“地区首讨”奖励；报酬为金币和物品，用 `CLAIM_QUEST_REWARD` 领取。

### 3.1.1 前置任务

每章两个前置任务，**类型各章不同**，全部完成后才能接收尾战；两个前置任务不分先后。六种类型：

| 类型 | 完成条件 |
| --- | --- |
| 派遣 | 章节开放之后出发的一次派遣满 N 日、地区不限，返程那一刻自动完成；一次派遣只计入最早一个还没完成的章节 |
| 提交材料 | 用 `COMPLETE_STORY_STEP` 从仓库提交指定数量，**扣除**（材料来源不限） |
| 副本宝箱找物品 | 在指定固定经典远征的某张图里找到一只旧箱子，取得任务物品（不可出售、不扣除）；箱子只在**对应章节开放之后**、**该远征里**出现，整趟完整通关后入库，每个账号一次；仓库里持有即完成 |
| 单挑 | `START_STORY_DUEL`：选一名己方角色，对手是**随机生成的人物**（名字随机，写成“名字（刮名人）”这样的形式）：等级 = 现役名册里的**最高等级** +1（第 3、5 章）／+2（第 8 章），职业是与应战角色**同阶级**（同一 stage：初级／中级／上级／最上级／神将级）的**随机**一个，只从目录里可用、有攻击手段的人类职业里按种子挑（纯治疗、兽龙种族职业不参与），免得对手不会还手；借小型经典图，推进 1 日，**真实死亡**；获胜完成，失败可再次挑战（再打会换一个随机人物）；不算地区讨伐 |
| 普通竞技场胜场 | 章节开放之后在普通竞技场赢 N 场（只计进攻胜利，不计投降） |
| 酒馆小游戏胜次 | 章节开放之后在酒馆小游戏里赢 N 次（返还高于下注） |

| 章 | 前置任务 1 | 前置任务 2 |
| --- | --- | --- |
| 1 | 酒馆小游戏胜 2 次（庆典前的热身） | 普通竞技场胜 2 场（擂台上的熟面孔） |

武器的档次随章节上升（C 级杀手系 → B 级 → A 级银／勇者系），都是可交易的普通武器，不是唯一武器。

**新增的两种战斗消耗品**（目前只作奖励，不进商店）：特效药（回复全部 HP，1 次）和解毒药（解除战技造成的中毒，不回复 HP，2 次）。中毒在受害者所在阵营的行动阶段末尾扣 5% HP 并禁止追击，且只持续到那个阶段结束，所以解毒药要在中毒的那个阶段里用。

**数值依据**（按现有系统的概率和频率估算，待人工试玩校准）：
- 普通竞技场每季 1 个竞技日、每个竞技日 3 场进攻，一年约 12 场；胜场要求 2／3／3，按五成胜率大约需要一到两个竞技日，不会拖住一章。
- 酒馆小游戏每季最多 6 局；猜大小胜率约 49%（出豹子通吃），青蛙最高 40%。2 次胜利一个季度约 88%，3 次约五成、两个季度基本稳妥，所以酒馆任务要求 2／3。
- 派遣 3～6 日远小于一年 500 日，只占队伍的时间。
- 提交材料：矿石 ×8、药草 ×15，按王都商店价约 1000～1200 金币，是该章金币报酬的两到三成；材料也能自己种、派遣带回。
- 单挑：对手等级为名册最高等级 +1／+1／+2，同阶级随机职业，真实死亡。应战者比对手低 3 级以上时，页面要求先勾选确认风险；接口本身不拦。

说明：副本找物品最多只有 4 处，因为只有六条固定经典副本里有宝箱，随机副本是生成地图没有宝箱；箱子位置在该图离出击点最远的四分之一可达区域，位置固定。酒馆在第 2 年（第 500 日）开放，第 1 章的酒馆任务要等到那时才能计数。旧档里已被旧按钮记为完成、收尾战还没打的章节，不受前置任务限制。线索仍只有收尾战地图里的一只，前置任务不另给线索。

### 3.3 庆典折扣

- 范围：只有王都每月商店（`SHOP_STOCK`）的买入价；地区声望商店、铁匠铺生产成本、出售价不变。
- 整店打折，**每月限量的稀有品（不朽盾、能力药、转职印）也参与**，会降到原价的 35%～50%。如不想这样，需要排除这几类。
- 前端：商店行显示原价划线和“庆典 −N%”标签。

## 4. 待定

- **隐藏终局首领**：所在高难地区、解锁条件、首领图与奖励（用户另行设计）。现有 `GET_STORY.finalBoss` 仍指向挑战塔终层，待替换。
- 主线报酬、公共经验、伙伴任务报酬、前置任务的天数、材料数、胜场数和单挑对手等级的校准；主线任务的难度是否需要按队伍规模调整。
- 非战斗任务是否也给线索（现在每章只有收尾战一条）；材料是否限定来源（现在不限）。
- 对白与过场的呈现方式：目前只有任务简报、线索说明和后记文字，没有战斗内对话。
- 伙伴任务是否需要专属新道具；更多固定人物加入后的扩展方式。
- 稀有品是否排除出庆典折扣。
