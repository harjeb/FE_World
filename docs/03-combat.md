# 03 战斗规则

> 本文公式为历史原型口径。2026-10-16已确认幸运与魅力沿用《万缕千丝》原作职能，精确系数仍需核对原作资料，不能将下文混用的系列公式直接标为官方。耐久、永久死亡和装备回收以[00](00-game-design.md)为准；代码对齐情况见12。

野外、主线关、竞技场使用**同一个战斗引擎**。玩家（或 Agent）总是操作己方；对手一律由服务端规则 AI 操作：野外是关卡里的敌军，竞技场是其他玩家的防守快照（AI 行为模式由防守方预设，见 05）。

## 地图与地形

- 正方形网格，坐标 `[x, y]`，左上为 `[0, 0]`。随机野外与非任务副本按战场方案使用 18×18、24×22 或 24×24；竞技场与经典地图保留各自尺寸、出战人数、回合上限和胜利条件。
- 随机战场有交错遭遇、分进合击、分散据点三种部署。布局和地形一起旋转、镜像、偏移；分进合击由隔墙与绕行通道将两支小队分开，地面部队不能开局立即汇合。详见 [10](10-random-map-generator.md)。
- 上场上限由地图与难度决定：交错遭遇普通4／困难6，分进合击普通6／困难8，分散据点普通8／困难8。敌军数量独立于我方实际出战人数；少带人不会减少敌军。
- 出发前展示准确地形、敌军位置、小队与落点。`unitIds`按提交顺序部署，第一个是主将；超员、重复角色或不可出战角色会被拒绝，不再静默截断。网页可调整顺序并在头像右下角显示序号，排序保存在当前浏览器并按账号隔离；改变排序会使旧预览失效。
- 每格有一种地形；单位不能穿过敌方单位，可以穿过友军（但不能停在友军所在格）。

「—」表示不可进入。**飞行单位不享受地形的回避和防御加成**（与原作相同）。**地形防御只挡物理伤害**，魔法、法术与魔法武器攻击不计（2026-10-19 确认）。地形回避的负值（浅滩 −10）照常扣；削减地形回避的战技只减正加成。

冬季（每年 D375–D499）出发的新战斗，将所有平地／草地改成雪地，水域和浅滩改成冰面；道路、桥、室内石地板及其他地形不变。按每张图的出发日冻结季节，跨季支付行动日、重连或回放不会重新改图；已存在的战斗不补刷地形。

移动加减只按本次行动的起点算一次，与技能修正叠加，最低仍可移动1格；定身优先、移动为0。飞行不吃雪地减速、也不获得冰面加速。重甲标记（包括铁甲骑兵、英勇骑士）经过及落脚的冰格立刻变为水域，传送只影响起点和落点、不影响中间格。碎冰不会自行恢复，不额外扣血；站在碎冰处的单位可以离开，但之后地面单位不能重新踏入水域。碎冰记录为`terrain`事件，玩家、AI和Agent使用同一套范围、路径与战斗状态。

「字符」是文本地图和终端预览里的写法。[像素素材](../design/pixel-art/README.md)、随机地图生成器（`backend/common/maps/map.ts`）和本表使用同一套字符，测试会检查生成器与像素画法是否对得上。

## 回合流程

- 一个回合 = 玩家阶段 → 敌方阶段（也可能有第三方阵营）。玩家总是先手，竞技场中即进攻方先手。
- 在己方阶段，每个未行动的单位可以执行**一次「移动 + 行动」**，单位之间的顺序任意：
  - 移动：移动到可达格（也可以原地不动）。
  - 行动（任选其一）：攻击 / 用杖 / 用道具 / 与相邻友军交换物品 / 压制（站在王座上） / 待机。
  - 舞者与神乐神将可以用「舞蹈」让一名**相邻**且本阶段已行动的友军再次行动；目标距离固定为 1，不能对远处友军生效。同一目标在每个己方阶段最多接受一次再行动。
- **移动和行动作为一步原子提交**，提交后不能悔棋。这样协议简单，也不存在「先移动看看再撤回」带来的信息泄漏。
- 所有单位行动完，或主动结束阶段（剩余单位自动待机），就轮到对方。

## 战斗公式

一次战斗交锋：攻击方出手 → 防守方若在射程内则反击 → 攻速领先 ≥ 4 的一方追击一次。勇者系武器每次出手连击两次。

| 量 | 公式 |
| --- | --- |
| 攻速 | 速 − max(0, 武器重量 − 体格) |
| 攻击力 | 力（理魔法用魔）+ (武器威力 + 三角伤害修正) × 特效倍率 |
| 伤害 | 物理：max(0, 攻击力 − 防 − 地形防御)；魔法：max(0, 攻击力 − 魔防)，地形防御不计 |
| 命中 | 武器命中 + 技 × 2 + 运 ÷ 2 + 三角命中修正 + 技能 |
| 回避 | 攻速 × 2 + 运 + 地形回避 + 技能 |
| 显示命中 | clamp(命中 − 回避, 0, 100) |
| 必杀 | 武器必杀 + 技 ÷ 2 + 技能 |
| 显示必杀 | clamp(必杀 − 对方运, 0, 100) |
| 必杀伤害 | 伤害 × 3 |
| 追击 | 攻速差 ≥ 4（刺客为 3） |

- **武器三角**：剑克斧、斧克枪、枪克剑。优势方命中 +15、伤害 +1，劣势方反之。弓、理、杖不参与三角。
- **特效**：弓对飞行、斩马刀对骑乘、破甲枪对重甲，武器威力 × 3。
- 所有除法向下取整。

## 随机数

- 每场战斗有一个服务端生成的**随机种子**，对局结束前不公开；之后所有随机判定都从该种子派生的确定性序列中依次抽取（PRNG 状态随战斗状态保存）。
- **命中用双随机数（2RN）**：抽两个 0–99 取平均，小于显示命中则命中。高命中更可靠、低命中更难中，减少「95% 打空」的挫败感。
- 必杀用单随机数（1RN）。大盾等概率技能用 1RN。
- 战斗预测只返回概率，不暴露随机序列。
- 复盘：初始状态 + 种子 + 指令序列 → 完整重现（见 07）。

## 经验

设 Δ = 敌方有效等级 − 己方有效等级（有效等级为保留的总等级）。**Δ≤−5时，有伤害的交战或击杀总经验固定为1，首领也不再叠奖励。**其余情形如下：

| 情形 | 经验 |
| --- | --- |
| 参与战斗、造成伤害、未击杀 | max(1, (31 + Δ) ÷ 3) |
| 参与战斗、未造成伤害且未击杀 | 0 |
| 击杀 | 有伤害的交战经验 + max(0, 20 + Δ × 3)；击杀首领再 +40，单次最多100 |
| 使用杖 | 12（当前实现；不按治疗对象等级使用击杀衰减） |

- 防守方被攻击时（反击）同样按上表获得经验。
- **只有在本场战斗里实际交过手、用过杖的单位才有经验。** 谁去补刀、谁去收人头，是火纹养成的核心决策，Agent 也要面对。
- 竞技场战斗**不给**经验（快照是冻结的），奖励按积分另算（见 05）。

## 胜负条件

| 条件 | 适用 |
| --- | --- |
| 击败全部敌人 | 野外、竞技场 |
| 击败敌方首领 / 主将 | 野外（部分地图）、竞技场 |
| 压制王座（首领或主将站上王座并执行「压制」） | 野外（部分地图）、竞技场 |
| 坚守 N 回合 | 野外（部分地图） |
| 回合上限 | 竞技场：进攻方在上限内未达成胜利条件即判负（上限由地图决定） |

压制地图（暂定）：只有压制王座算胜利，全歼守军也要再压制；只有主将能压制，所以进攻方主将被击败即判负。

野外战败（全员撤退，或者「保护目标」阵亡）：本场奖励减半，阵亡单位进入「重伤」状态（见 04）。

## 服务端规则 AI

野外敌军和竞技场防守方都由它操作，不依赖 LLM：

- 每个单位带一种行为模式：**进攻**（主动追击）、**伺机**（敌人进入自身攻击范围才动）、**固守**（原地不动，只反击）、**护卫**（跟随首领/主将）、**治疗优先**（先治疗，再考虑攻击与跟队）。随机敌军按模板的治疗能力识别治疗职业；经典地图的自动护卫安排不覆盖治疗职业，明确指定的固守首领与已保存的竞技场行为保留。
- **普通难度**已经会集火、补刀和动态安排出手顺序。攻击评分综合预计伤害、击杀概率、预计反击伤害、自身死亡概率、剩余HP、地形和其他玩家单位的威胁；还会估计不同队友从不重复落点出手的伤害，对有望合力击杀的目标加分。每次真实行动后重新计算，不预知命中和必杀结果。每个武器／目标保留四个候选攻击落点；这是协同伤害估计，不保证路线或连击一定成功。
- 治疗优先会使用合法治疗杖和治疗法术书，按当前HP／最大HP比例优先救急；比例相同时选敌方威胁较少、移动较短的位置。沉默、熟练度、教材、剩余次数和不可治疗状态仍按引擎校验，不治疗石化或治疗免疫单位。
- 没有可执行的治疗或攻击时，向够不到的伤兵靠近；无人受伤时跟随最接近敌人的友军战斗单位，在前排后方约两步保持支援位置。移动按地形路径计算，并给可被敌人攻击的格子加罚分；到位后不为同分位置反复挪动。威胁范围包含合法攻击法术书，但不预测敌方多步组合、战技或未来移位；这是局部避险，不保证治疗者绝对安全。
- **困难解锁**（`rules-v13`／目录28）：普通野外胜利只解锁该地区的困难野图；普通随机大副本完整通关只解锁该地区对应副本；以任务进入的连战副本完整通关只解锁该副本 ID。失败、撤离、中间图、困难胜利均不解锁。单图地区任务（含经典单图）保持普通与一次性任务流程，不设困难入口。解锁后每次出征仍默认普通，可主动选择困难；连战副本可重打，但首通探索度和任务固定奖励不重复发。旧档缺失解锁字段时按真实普通胜利／完整通关历史补齐，缺失难度视为普通，不把笼统的地区讨伐或任务完成标记当作证明。
- 野外与连战副本可以在解锁后、出征前选择`normal`／`hard`，默认普通。难度存入战斗和整趟远征，继续、刷新、重连不会改变；缺失字段的旧档按普通处理。`rules-v12`／目录27起，困难新生成敌军（含经典地图和每波增援）目标增加50%人数（额外人数向上取整、至少1人，以敌阵附近合法空位为限）；等级独立随机+2～5、上限99，先按新等级计算基础属性，再将HP随机增加20～35%，力量、魔力、技巧、速度、幸运、防御、魔防、魅力各独立随机增加10～25%（向上取整、至少+1且不超过职业上限），体格随机+1～3。职业与移动力不变；升级合法武器／法杖并配套熟练度，保留原有实用装备选项。固定战斗／单位种子决定加成，刷新不会重随机，也不会对已保存敌军重复加成或回填旧战斗／回放。任务固定奖励与行动日成本不变，但更多、更高等级敌军自然带来更多战斗经验与掉落机会。部署前先结束进行中的活动、战斗与远征并备份。竞技场、年度赛事与挑战塔暂保持普通规则。
- **困难难度**在普通的候选上增加连续三次行动的有界搜索：每个武器／目标考虑八个攻击落点，另取不同单位的移动备选，包括暂时让开攻击位置。每层最多八个分支、保留四个方案，每次决策最多执行72次模拟，每个敌方阶段总预算432次（最多六次完整搜索），用尽后继续用普通档的集火与动态出手策略完成剩余行动；只有至少两名单位可能形成攻击／治疗配合时才搜索（判定包括可由友军腾出的攻击格），远处无人能交战时直接沿普通策略推进。用生产战斗引擎在独立副本中验证移动、治疗、反击、占位、死亡、消耗和碎冰变化，比较后续整体收益。因此能发现“前排先让位，后排再通过窄道攻击”这类普通即时评分漏掉的方案。
- 推演使用固定的独立模拟随机种子，不读取或消耗真实战斗的随机流；预测仍可能与实际命中／必杀不同，每次真实行动后都会重算。搜索只覆盖当前敌方阶段最多三名单位，不推演玩家下一回合，也不穷举战技、功能法术和联动移位；候选和束宽限制可能漏掉更优方案。两档都保留固守、护卫范围、睡眠、石化和混乱约束。我方自动操作与混乱仍使用单单位决策。
- AI 的决策是确定的（同样的局面做同样的决定）；战斗中的命中、必杀仍然按种子随机。
- **竞技场的胜负很大程度上取决于这个 AI 的水平**：AI 太弱，防守永远是送分；太强，进攻方没法赢。所以它需要单独打磨，并用模拟器统计攻防胜率（见 07）。
