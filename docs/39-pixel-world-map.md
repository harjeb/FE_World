# 39 像素世界地图

更新：2026-10-20。关联：[00 玩法](00-game-design.md) §8.1.1（十二地区路线）、`design/world-map/world-map.svg`（原设计示意图）。

世界地图页改为街机大地图风格的像素图：**240×160 格，每格 4 像素，整图 960×640 像素**，用最近邻放大显示；点地标选择地区，双击已开通的地区直接进入任务页。路线规则（探索度满 100 才开放相邻新路线、不耗行动日）不变，仍由服务端的 `GET_STATE.world` 决定。

## 生成与绘制（都是确定性的纯函数）

| 部分 | 内容 | 位置 |
| --- | --- | --- |
| 格子数据 | 噪声生成大陆、海岸、森林、丘陵、山、雪；十二地区按主题改写地貌（平原／林地／丘陵／要塞丘陵／湖／遗迹／山岭／风崖／沙漠／火山灰／墓地／雪原）；站点位置沿用设计图百分比；道路按 `WORLD_EDGES` 连接，跨水自动架桥 | `common/maps/world-tiles.ts` |
| 像素画 | 每种地形多个 4×4 图案按格坐标哈希挑选；十三个 16×16 像素的地标（王都城堡、农舍、树屋、矿洞、要塞、湖镇、古都、兽窟、风崖塔、金字塔、龙巢、陵墓、神殿） | `common/maps/world-art.ts` |
| 交互 | 拖动平移、滚轮／加减号缩放、方向键平移；叠加迷雾（未开通）、旗帜（已开通蓝／已讨伐绿／可选路线铜色并闪框）、名字、选中框 | `frontend/src/world/PixelWorldMap.tsx` |

地图下方保留可用键盘操作的地区列表（原来的地区按钮，含探索度）；未开通地区不可选择，与路线规则一致。生成结果由测试固定：每个站点在陆地、所有站点可从王都走到、道路连通、各地区有自己的地貌、每个地标不同。
